## 온셰이프 장점

- 무료이다. 또 프로버전은 한달에 12만원?
- 웹상에서 작업 가능. 설치가 필요없음. 어디서든지 작업이 가능. 
- 또한 고난이도 3d모델링 까지 가능.
- 어셈블리 기능 : 여러 부품을 조립할 때 만들때, 조립이 가능 아구가 잘 맞는지 확인 가능. 
- 여러분 작업내용을 다른 팀원과 같이 작업하기 좋음.
- 모바일 어플이 있어서 테블릿에서 작업가능.
- 온셰프의 파트너 앱에서 설치하면 다양한 고급기능 사용가능
- 한글 사용 가능해서 쉽게 접근 가능.
- 웹상에서 자료가 매우 풍부해서 쉽게 찾아 볼 수 있음.
- 크롬에서 최적화 되어 있음.
## 튜토리얼

- 왼쪽의 공개 탭을 누르면 다른 사용자들이 모델링한 내용들을 쉽게 접근 가능.
### 구속조건의 사용

- 구속조건이 생기면 검은색으로 변함(구속조건이 없을 시 파란색 스케치가 나옴)
- 과다 구속이 되면 과다 구속된 조건들이 빨간색으로 보임. 필요없는 구속조건들이 삭제되어야 함.
### 회전

- 2차원 스케치 생성 → 회전하여 3d구체 만듬.
