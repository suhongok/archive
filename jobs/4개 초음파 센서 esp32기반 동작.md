## 📌 1. 사용한 센서 및 하드웨어

### 1) 초음파 센서 – AJ-SR04M (방수형)

- 특징: Trig/Echo 방식 + UART(RX/TX) 겸용
- TRIG 핀은 공유 가능
- 가까운 물체(20cm 이하)와 좁은 물체(손바닥 등)에는 반응 불안정 → 센서 특성상 정상 동작
### 2) 부저(Buzzer)

- 단순 Piezo가 아니라 “능동형 Active Buzzer”로 판단됨
- → LOW 신호에서 울림 / HIGH에서 조용
- 주파수(tone)는 반응하지 않고, ON/OFF 패턴으로 제어해야 함
### 3) M5Stack SPK2 (MAX98357 I2S 스피커)

- I2S 기반 Class-D 오디오 앰프
- 라즈베리파이·ESP32 모두 TTS 출력 가능
- 고음질, 높은 출력 → 지게차·로봇 안내용에 적합

## 📌 4.

## 부저 테스트 및 성능 확인

### 확인된 사실

- 연결한 부저는 tone()이 아니라 LOW 신호에서 울리는 Active Buzzer
- → digitalWrite(pin, LOW) : ON
- → digitalWrite(pin, HIGH) : OFF
### 부저 단독 테스트 코드로 검증 완료

1초 OFF → 1초 ON 패턴 확인됨.

## 초음파 2채널 확장 (공유 TRIG + 별도 ECHO)

### 구성

- TRIG → GPIO14
- ECHO1 → GPIO13
- ECHO2 → GPIO12
### 방식

- TrigPulse()는 공유
- Echo 핀을 인자로 전달 → 독립 측정
- 센서 간 50ms 딜레이로 잔향 최소화

## 📌 7.

## M5Stack SPK2(MAX98357) 기반 TTS 오디오 시스템

### 장점

- 라즈베리파이에서 TTS 엔진(PicoTTS, EdgeTTS, Qwen2.5 등) 음성을 그대로 출력 가능

- Class-D 앰프 → 출력 크고 왜곡 적음
- 지게차/로봇 경고음/안내음에 최적화
