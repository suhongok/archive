**상태**: 진행 중  
**우선순위**: 높음

#### 📌 목표
- cmd_vel (명령 속도) 표준 통신 프로토콜 구축

명령: cmd_vel (속도 명령)

### 2. 메카넘휠 제어 시스템 고도화

**상태**: 진행 중  
**우선순위**: 높음

#### 📊 기술 로드맵

```
Phase 1: 전기 기반 제어
    ↓
Phase 2: 디지털 제어 시스템
    ↓ (현재 위치)
Phase 3: AI 통합 제어
    ↓
Phase 4: 완전 자율 주행
```

#### 🔄 개선 사항

| Phase | 기술 | 특징 |
|-------|------|------|
| 1 | 전기식 제어 | 기본적인 모터 제어 |
| 2 | 디지털 제어 | 마이크로컨트롤러 기반 정밀 제어 |
| 3 | AI 통합 | 머신러닝 기반 최적화 |
| 4 | 자율주행 | 완전 자동화 |

#### 📌 현재 작업
- Phase 2 → Phase 3 전환 진행 중
- ESP32-S3 USB 통신으로 Phase 3 기초 마련
- ROS2 통합 검토
