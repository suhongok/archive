# 메카넘 AI 지게차 - 실내 물류용 지능형 지게차 개발

> **생성일:** 2026-01-09
> **상태:** 기획 중

---

## 1. 프로젝트 개요

### 목표
메카넘휠 + 피지컬 AI 기반 **실내 물류용 지능형 지게차** 개발

### 타겟 시장
- 물류창고
- 스마트팩토리
- 반도체 클린룸
- 유통센터

### 핵심 가치
| 항목 | 기존 지게차 | 메카넘 AI 지게차 |
|------|------------|-----------------|
| 이동 | 전후진 + 회전 | **전방향 이동** (360도) |
| 조작 | 운전자 필수 | 원격/음성/자율 |
| 안전 | 수동 확인 | **AI 자동 감지** |
| 적재 | 수동 작업 | **자율 적재/하차** |

## 3. Phase별 상세 기능

### Phase 1: 원격제어 + AI 기반 안전 기능

| 기능 | 설명 | 기반 기술 |
|------|------|-----------|
| **원격 제어** | 무선 컨트롤러/앱 기반 조종 | Bluepad32, ESP32-S3 |
| **사람 인식** | 전방 카메라로 사람 감지 | 비전 AI (K230/Hailo-8) |
| **충돌 감지** | 주변 장애물 실시간 감지 | ToF 센서 + AI |
| **자동 정지** | 위험 감지 시 즉시 정지 | SafetyFilter 로직 |
| **경보 알림** | 사람 접근 시 음성/시각 경보 | ESP-NOW 연동 |

**기존 기술 연계:**
- `ESP32 메카넘 로봇 - 사람 추종 및 제어 고도화` 프로젝트의 PersonVision 활용
- 사람 인식 → 경보 발생 → 안전 거리 미확보 시 자동 정지

---

### Phase 2: 음성 기반 명령 인식 + 자율 동작

| 기능 | 설명 | 기반 기술 |
|------|------|-----------|
| **음성 인식** | 한국어 음성 명령 인식 | STT (Google Speech) |
| **명령 해석** | 자연어 → 로봇 제어 명령 변환 | LLM (gemma3:4b) |
| **경로 계획** | 목적지까지 최적 경로 계산 | A* / RRT |
| **자율 주행** | 계획에 따른 자동 이동 | SLAM + 경로추종 |
| **TTS 응답** | 로봇 상태 음성 피드백 | gTTS |

**음성 명령 예시:**
```json
{
  "사용자": "A 선반으로 이동해",
  "로봇 응답": {
    "response": "A 선반으로 이동합니다",
    "action": "move",
    "target": "shelf_A"
  }
}
```

**기존 기술 연계:**
- `jetson orin nano llm사용시도` 프로젝트 결과 활용
- Jetson Orin + gemma3:4b 조합 검증 완료 (반응속도 ~1초)

---

### Phase 3: 물건 정리 자율 적재 기능

| 기능 | 설명 | 기반 기술 |
|------|------|-----------|
| **선반 인식** | VLM으로 선반 구조/위치 파악 | VLM (GPT-4V류) |
| **물건 인식** | 적재 대상 물건 식별 | Object Detection |
| **자동 하차** | 선반에서 물건 순차 하차 | 그리퍼 제어 |
| **자동 적재** | 지정 위치에 물건 적재 | 모션 플래닝 |
| **정리 자동화** | 적재된 물건 선반별 정리 | Task Planning |

**시나리오 예시:**
```
1. "B 선반 물건 모두 하차해" 명령
2. VLM으로 B 선반 위치/물건 인식
3. 선반 앞으로 자율 이동
4. 물건 순차 하차 (위→아래)
5. "완료했습니다" 음성 응답
```

## 4. 기술 스택

### 하드웨어

| 구성요소 | 사양 | 역할 |
|---------|------|------|
| **메인 컴퓨터** | NVIDIA Jetson Orin Nano 8GB | VLM/LLM 추론, 자율주행 |
| **제어 MCU** | ESP32-S3 | 모터 제어, 센서 처리 |
| **메카넘휠** | ATIDrive 4륜 | 전방향 이동 |
| **비전** | 스테레오 카메라 | 깊이 인식, 객체 감지 |
| **마이크** | USB 마이크 | 음성 명령 입력 |
| **스피커** | 앰프 내장 스피커 | TTS 출력, 경보 |

### 소프트웨어

| 계층 | 기술 | 용도 |
|------|------|------|
| **AI 추론** | NVIDIA TensorRT, Ollama | VLM/LLM 가속 |
| **로봇 제어** | ROS2 (Humble) | 노드 관리, 통신 |
| **모터 제어** | Allturn USB NDJSON Protocol | ESP32 ↔ Jetson 통신 |
| **음성** | SpeechRecognition + gTTS | STT/TTS |
| **비전** | OpenCV, YOLO | 객체 감지 |

## 5. 메카넘휠 제어

### Allturn USB NDJSON Protocol

```json
{
  "cmd": "vel",
  "linear_x": 0.5,
  "linear_y": 0.3,
  "angular_z": 0.0,
  "timestamp": 1704787200
}
```

### 메카넘휠 속도 계산

```
FL (Front-Left)  = vx + vy + ω
FR (Front-Right) = vx - vy - ω
RL (Rear-Left)   = vx - vy + ω
RR (Rear-Right)  = vx + vy - ω
```

|------|------|
