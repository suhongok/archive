### 🔧 기술 개발 현황

#### 1️⃣ ESP32-S3 Native USB 기반 JSON 통신 구축
- **상태**: 진행 중 (2025년 12월 23일 기록)
- **우선순위**: 높음
- **목표**: cmd_vel (명령 속도) 표준 통신 프로토콜 구축
- **프로토콜**: Allturn USB NDJSON Control Protocol v1
- **형식**: NEWLINE Delimited JSON
- **활용**: 메카넘휠 로봇 속도 제어, ROS2 호환성 고려

**기본 명령 구조**:
```json
{
  "cmd": "vel",
  "linear_x": 0.5,
  "linear_y": 0.0,
  "angular_z": 0.3,
  "timestamp": 1703338020
}
```

지원 명령: `vel` (속도), `stop` (정지), `status` (상태 조회), `calibrate` (캘리브레이션)

#### 2️⃣ 메카넘휠 제어 시스템 고도화
- **상태**: 진행 중 (Phase 2 → Phase 3 전환)
- **우선순위**: 높음

**기술 로드맵**:
```
Phase 1: 전기 기반 제어
    ↓
Phase 2: 디지털 제어 시스템 (현재 위치)
    ↓
Phase 3: AI 통합 제어 (진행 중)

Phase 4: 완전 자율 주행
```

#### 3️⃣ 사이버트럭 AI 기능 통합
- **상태**: 계획 중
- **우선순위**: 중간

- **AI 기능**: 인식(카메라, LiDAR, IMU) → 계획(경로, 충돌회피) → 제어(모터, 속도)
