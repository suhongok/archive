## 2. 기술 요구사항

본 장에서는 메카넘 고소작업대의 핵심 기술 요소인 메카넘 휠 시스템과 리프팅 시스템의 세부 사양을 정의합니다. 각 시스템은 안전성과 성능을 동시에 만족해야 하며, 상용화 가능한 수준의 내구성과 신뢰성을 확보해야 합니다. 특히 메카넘 휠의 정밀한 제어를 통해 mm 단위의 정확한 위치 제어가 가능하도록 설계합니다.

### 2.1 메카넘 휠 시스템
#### 2.1.1 휠 사양
- **휠 직경**: 200-300mm
- **로울러 개수**: 각 휠당 8-12개
- **로울러 각도**: 45도
- **재질**: 고강도 알루미늄 합금 + 우레탄 로울러
- **하중 용량**: 각 휠당 500kg 이상

#### 2.1.2 구동 시스템
- **모터 타입**: 서보 모터
- **출력**: 각 휠당 1-2kW
- **감속비**: 1:50 ~ 1:100
- **제어 방식**: 벡터 제어
- **피드백**: 엔코더 + 홀센서

### 2.2 리프팅 시스템
#### 2.2.1 승강 메커니즘

- **승강 속도**: 0.3-0.5 m/s
- **하중 용량**: 300-500kg
- **안전율**: 3:1 이상

#### 2.2.2 유압 시스템

- **작업 압력**: 200-300 bar
- **유압 실린더**: 다단 텔레스코픽
- **안전 밸브**: 과부하 보호 장치 내장

## 3. 제어 시스템 설계

제어 시스템은 메카넘 휠의 복잡한 동작을 실시간으로 관리하고, 작업자의 안전을 보장하는 핵심 요소입니다. 다중 센서 융합을 통한 정확한 상태 인식과 예측 제어 알고리즘을 적용하여 부드럽고 안정적인 동작을 구현합니다. 또한 계층적 제어 구조를 통해 시스템의 확장성과 유지보수성을 확보합니다.

### 3.1 제어 아키텍처
```
상위 제어기 (Main Controller)
├── 이동 제어 모듈 (Motion Control)
│   ├── 메카넘 휠 제어
│   ├── 경로 계획
│   └── 장애물 회피
├── 승강 제어 모듈 (Lift Control)
│   ├── 높이 제어

### 3.2 센서 시스템
#### 3.2.1 위치 및 자세 센서

#### 3.2.2 안전 센서
- **기울기 센서**: 작업대 수평 상태 감시
- **하중 센서**: 과부하 감지
- **근접 센서**: 작업자 안전 확보
- **온도 센서**: 모터 및 유압 시스템 열 관리

### 3.3 제어 알고리즘
#### 3.3.1 메카넘 휠 제어
```python
# 메카넘 휠 역기구학
def mecanum_kinematics(vx, vy, omega):
    """
    vx: 전진/후진 속도
    vy: 좌우 이동 속도  
    omega: 회전 속도
    """
    v_front_left = vx - vy - omega * L
    v_front_right = vx + vy + omega * L
    v_rear_left = vx + vy - omega * L
    v_rear_right = vx - vy + omega * L
    
    return [v_front_left, v_front_right, v_rear_left, v_rear_right]
```

#### 3.3.2 자동 수평 제어

# PID 제어를 통한 수평 유지
def auto_leveling(target_angle, current_angle):
    error = target_angle - current_angle
    pid_output = kp * error + ki * integral + kd * derivative
    return pid_output
```
