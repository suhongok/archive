## 1. 왜 스마트팜에 이 기술이 필요한가?

### 🌱 스마트팜 시장 현황과 문제점

**급성장하는 스마트팜 시장:**
- 국내 스마트팜 시장 규모: 연 5,000억원 (2024년 기준)
- 연평균 성장률: 15% (세계 최고 수준)
- 정부 지원: 2027년까지 7,000ha 확대 목표
- 대형 스마트팜 증가: 평균 면적 3배 확대 (1ha → 3ha)

**🚧 현재 농업용 고소작업대의 심각한 문제점:**

**시장 공백 상태:**
- 농업 전용 고소작업대 제품 거의 전무
- 기존 건설용 장비를 억지로 사용 중
- 농업 환경에 최적화된 솔루션 부재

**스마트팜 환경의 특수성:**
- 온실 통로 폭: 1.2-1.5m (매우 좁음)
- 작물 보호 필수 (접촉 시 손상)
- 높이 6-8m의 수직 농업 시설
- 정밀한 위치 제어 필요 (±5cm 이내)
- 하루 8-12시간 연속 작업

### 💡 메카넘 휠이 스마트팜 문제를 해결하는 방법

**메카넘 휠이란?**
- 바퀴에 작은 롤러가 비스듬히 달린 특수 바퀴
- 앞뒤, 좌우, 대각선, 제자리 회전 등 모든 방향으로 이동 가능
- 마치 게처럼 옆으로도 자유자재로 움직임
- 농업 로봇과 동일한 이동 기술

**🍅 실제 스마트팜 작업 예시:**
```
기존 방식: 토마토 고단 수확 작업 시
앞진 → 후진 → 회전 → 앞진 → 위치조정 → 작물 접촉 위험 (10분 소요)

메카넘 작업대: 
바로 옆으로 이동 → 정확한 위치 도달 → 작물 무손상 (2분 소요)
```

**🥬 스마트팜별 적용 사례:**
- **수직농장**: 층별 이동 + 좌우 슬라이딩
- **온실농업**: 통로 직진 + 측면 접근
- **식물공장**: 선반간 자유이동 + 정밀제어

**🎯 프로젝트 목표 및 범위**

메카넘 휠 기술을 스마트팜 전용 고소작업대에 적용하여 농업 현장의 한계를 극복하는 혁신적인 솔루션을 개발합니다. 좁은 온실 통로에서도 전방향 이동이 가능한 메카넘 휠의 특성을 활용하여 농작업 효율성을 50% 이상 향상시키고, 작물 손상을 최소화하는 것을 목표로 합니다.

**농업용 특화 개발 범위:**
- 스마트팜 환경 맞춤형 하드웨어 설계
- 농작물 보호 기능 내장 제어 시스템
- 온실 환경 대응 안전 시스템 구축
- 농업인 친화적 인터페이스 개발
- 실제 스마트팜에서 성능 테스트 및 검증
- 농업용 센서 및 장비 연동 기능

## 3. 스마트팜용 기술 구현 방법

### 🔧 농업 특화 핵심 기술 4가지

#### ① 스마트팜 최적화 메카넘 휠 시스템
**🌟 쉬운 설명:**
- **무엇인가요?** 온실 통로에 최적화된 4개의 특수 바퀴로 모든 방향 이동
- **어떻게?** 각 바퀴의 속도를 정밀 조절하여 작물 사이를 안전하게 이동
- **농업 장점:** 좁은 온실 통로에서도 자유로운 움직임, 작물 무손상

**⚙️ 스마트팜 특화 기술 사양:**
- **휠 직경**: 200mm (온실 바닥 홈 대응)
- **로울러 개수**: 각 휠당 12개 (45도 각도, 정숙 설계)
- **재질**: 고강도 알루미늄 합금 + 농업용 무독성 우레탄 로울러
- **하중 용량**: 각 휠당 300kg (농작업 도구 + 수확물)
- **모터**: 농업용 저소음 서보 모터, 각 휠당 1kW
- **감속비**: 1:80 (정밀 제어 최적화)
- **제어 방식**: 벡터 제어 + 고정밀 엔코더 피드백
- **특수 기능**: 토양 보호 압력 제한, 진동 최소화

**제어 알고리즘:**
```python
# 메카넘 휠 역기구학
def mecanum_kinematics(vx, vy, omega):
    """
    vx: 전진/후진 속도
    vy: 좌우 이동 속도  
    omega: 회전 속도
    """
    v_front_left = vx - vy - omega * L
    v_front_right = vx + vy + omega * L
    v_rear_left = vx + vy - omega * L
    v_rear_right = vx - vy + omega * L
    
    return [v_front_left, v_front_right, v_rear_left, v_rear_right]
```

#### ② 농작물 보호 스마트 제어 시스템  
**🌟 쉬운 설명:**
- **무엇인가요?** 농작물을 보호하면서 바퀴 4개를 정밀 조절하는 컴퓨터
- **어떻게?** 농업인도 쉽게 사용할 수 있는 직관적 조작
- **농업 장점:** 작물 손상 없이 정확한 위치 제어, 농업인 친화적 조작

**⚙️ 스마트팜 특화 기술 사양:**

제어 시스템은 메카넘 휠의 복잡한 동작을 실시간으로 관리하면서, 농작물 보호와 작업자 안전을 동시에 보장하는 핵심 요소입니다. 농업 환경 특화 센서 융합을 통한 정확한 상태 인식과 작물 보호 알고리즘을 적용하여 안전하고 효율적인 농작업을 구현합니다.

**농업 특화 제어 아키텍처:**
```
농업용 상위 제어기 (Agricultural Main Controller)
├── 스마트팜 이동 제어 모듈
│   ├── 메카넘 휠 정밀 제어
│   ├── 온실 통로 자동 경로 계획
│   ├── 작물 보호 장애물 회피
│   └── 토양 압력 모니터링
├── 농업용 승강 제어 모듈
│   ├── 작물 높이별 자동 조절
│   ├── 수평 유지 (기울어진 농지 대응)
│   ├── 진동 최소화 제어
│   └── 작물 접촉 방지 감시
├── 농업 환경 모니터링
│   ├── 온습도 센서 연동
│   ├── 작물 생장 감지
│   └── 수확 시기 판단 지원
└── 농업인 친화 인터페이스
    ├── 한글 터치 패널
    ├── 음성 안내 시스템
    └── 스마트폰 원격 제어
```

**농업 특화 센서 시스템:**
- **작물 보호 센서**: 접촉 방지 라이다, 작물 인식 카메라, 초음파 근접 센서
- **농업 환경 센서**: 온습도, 토양 수분, 조도, CO2 농도
- **위치 제어 센서**: RTK-GPS, IMU(9축), 온실 내 비콘 시스템
- **안전 관리 센서**: 기울기, 하중, 진동, 온도, 먼지 농도

#### ③ 농업 환경 특화 다중 안전 시스템
**🌟 쉬운 설명:**
- **무엇인가요?** 농작물과 농업인을 동시에 보호하는 스마트 안전 시스템
- **어떻게?** 작물 인식 카메라, 환경 센서 등으로 24시간 농장 감시
- **농업 장점:** 작물 손상 0%, 농업인 안전 100% 보장

**⚙️ 농업 특화 안전 기술:**

스마트팜에서는 농작물 보호와 농업인 안전을 동시에 고려한 특별한 안전 시스템이 필요합니다. 농업 환경의 특수성을 반영한 다층적 안전 장치를 구성합니다.

**농작물 보호 능동 안전 장치:**
- **작물 접촉 방지 시스템**: 작물 인식 AI + 접촉 방지 라이다
- **온실 구조 대응**: 기둥, 파이프 등 온실 구조물 자동 회피
- **토양 보호**: 토양 압력 제한으로 뿌리 손상 방지
- **환경 모니터링**: 온습도, 조도 변화 실시간 감지

**농업인 안전 장치:**
- **농업용 비상정지**: 작업대 및 지상 무선 제어부
- **온실 환경 대응 안전 가드**: 습기 방지 코팅 처리
- **농작업 도구 고정대**: 낫, 가위 등 농기구 안전 보관
- **미끄럼 방지**: 온실 바닥 습기 대응 특수 바닥재

**농업용 안전 표준 준수:**
- **농업기계 안전 기준**: 농촌진흥청 인증
- **온실 시설 안전 기준**: 농림축산식품부 기준
- **CE 마킹**: 유럽 농업용 장비 표준
- **ISO 4254**: 농업용 기계 안전 표준
- **방진/방수**: IP65 등급 (온실 환경 대응)

#### ④ 농업 최적화 수직 이동 시스템
**🌟 쉬운 설명:**
- **무엇인가요?** 온실 높이에 맞춰 부드럽게 올라가는 승강 시스템
- **어떻게?** 농작물 높이를 자동 인식하여 최적 작업 높이로 이동
- **농업 장점:** 토마토, 딸기 등 다양한 작물 높이에 자동 대응

### 🎮 농업인 친화적 사용법 (3단계면 끝!)

```
1단계: 전원 켜기 + 작물 종류 선택 (터치 한 번)
2단계: 가고 싶은 방향 터치 (상하좌우 버튼)
3단계: 작물 높이에 맞춰 자동 승강
```

### 🔋 농업용 리프팅 시스템 세부사항

**스마트팜 특화 승강 메커니즘:**
- **방식**: 정숙 가위식(Scissor) + 진동 최소화
- **최대 작업높이**: 8m (대부분 온실 높이 대응)
- **승강 속도**: 0.2-0.3 m/s (작물 보호 최적화)
- **하중 용량**: 250kg (농업인 + 농기구 + 수확물)
- **안전율**: 4:1 이상 (농업 환경 고려)
- **특수 기능**: 작물별 높이 프리셋, 수확량 무게 자동 감지

**농업용 유압 시스템:**
- **펌프 타입**: 저소음 가변 용량 펌프 (온실 정숙성 고려)
- **작업 압력**: 150-200 bar (안전성 최우선)
- **유압 오일**: 친환경 생분해성 오일 (작물 안전)
- **안전 밸브**: 과부하 + 진동 최소화 보호 장치
- **누유 방지**: 완전 밀폐형 시스템 (토양 오염 방지)

- 현재 시장 규모: 연 5,000억원 (2024년 기준)

**스마트팜 확산 가속화:**

## 5. 스마트팜 특화 성능 사양

### 📏 농업 환경 최적화 성능 지표

#### 🚜 농업용 이동 성능
- **최대 속도**: 3 km/h (온실 안전속도), 1.5 km/h (승강 시)
- **등판 능력**: 10도 (대부분 온실은 평지)
- **회전 반경**: 제자리 회전 (1.2m 통로에서도 가능)
- **측면 이동**: 무제한 (작물 사이 좁은 공간 이동)
- **위치 정밀도**: ±5mm (농작업 최적 정밀도)
- **통로 폭 적응**: 1.0m~2.0m 가변 대응
- **토양 압력**: 최대 2kg/cm² (뿌리 손상 방지)

#### 🌱 농작업 특화 성능
- **최대 작업 높이**: 8m (온실 표준 높이)
- **플랫폼 크기**: 2.0m × 1.0m (온실 통로 최적화)
- **작업 하중**: 250kg (농업인 + 농기구 + 수확물)
- **승강 시간**: 지상→8m 높이 60초 (작물 보호 속도)
- **수평 유지 정확도**: ±0.3도 (농작업 최적)
- **작물별 높이 프리셋**: 토마토(2.5m), 딸기(1.2m), 상추(0.8m) 등
- **수확물 적재함**: 100kg 용량 자동 계량

#### 🔋 농업용 전원 시스템
- **배터리 타입**: 리튬이온 (LiFePO4) 농업용 특수 설계
- **용량**: 60Ah (농작업 최적화)
- **연속 작업 시간**: 10시간 (농업인 작업 패턴 고려)
- **충전 시간**: 급속충전 1.5시간, 야간충전 4시간
- **배터리 수명**: 3,000회 충방전 (농업용 내구성)
- **온도 대응**: -10°C ~ +60°C (온실 환경)
- **습도 대응**: 95% 고습도 대응 (온실 특성)

#### 🛡️ 농업 환경 대응 특성
- **방진/방수**: IP65 등급 (먼지, 물 완전 차단)
- **소음 수준**: 45dB 이하 (온실 정숙성)
- **진동 수준**: 0.1G 이하 (작물 보호)
- **온실가스 대응**: CO2 고농도 환경 동작
- **친환경**: 무배출, 생분해성 오일 사용
