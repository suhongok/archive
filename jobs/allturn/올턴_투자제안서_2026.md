# 올턴(ALLTURN) 투자제안서

## 메카넘휠 기반 AI 자율이동로봇 전문기업

---

## Executive Summary

**올턴(ALLTURN)**은 메카넘휠 기반 360도 전방향 이동로봇을 자체 설계·제조하는 기술 스타트업입니다. 하드웨어(메카넘휠 직접 설계)와 소프트웨어(AI 제어 시스템)를 모두 보유한 국내 유일의 기업으로, 교육용·농업용·산업용 로봇 시장에 진출하고 있습니다.

| 구분 | 내용 |
|------|------|
| **회사명** | 올턴(ALLTURN) / 브랜드: ATIDRIVE |
| **설립** | 2023년 |
| **핵심 기술** | 메카넘휠 설계·제조, AI 기반 로봇 제어 |
| **주요 제품** | 교육용 로봇, 산업용 지게차/고소작업차, 농업용 로봇 |
| **진행 중 R&D** | 1억원 규모 험지전용 메카넘휠 연구 (2026년 4월 완료 예정) |
| **2026년 R&D 계획** | 3~5억원 규모 정부 연구비 수주 예정 |

## 1. 회사 소개

### 1.1 설립 배경
- **대표**: 자동차 공학 전공, 휠 복원 및 타이어 사업 운영 경험
- **설립 동기**: 기존 사업 경험을 바탕으로 혁신적인 이동 플랫폼 개발
- **핵심 역량**: 기계 설계 + 소프트웨어 개발 + AI 통합 능력

### 1.2 조직 구성

```
올턴(ALLTURN)
├── 경영진
│   ├── 이대표 (CEO/CTO) - 기술 총괄, 메카넘휠 개발
│   └── 임대표 (CFO) - 재무/경영 관리
│
└── 개발팀
    ├── 석사급 SW 연구원 - AI/임베디드 개발
    └── (확충 예정) HW/SW 엔지니어
```

### 1.3 핵심 브랜드: ATIDRIVE

**ATIDRIVE** = AllTurn + AI + Drive

> "360도 Precision Mobility, Powered by AI"
>
> 메카넘휠과 AI 제어 기술을 결합한 전방향 지능 구동 플랫폼

|------|----------|------|

### 2.3 시장 트렌드

**AGV에서 AMR로의 패러다임 전환**
- 2025년 기준 AGV 점유율 50% → 25%로 급락 전망
- AMR이 AI, LiDAR, GPS 등 첨단 기술로 AGV 대체
- **메카넘휠 기반 전방향 이동 기술이 핵심 경쟁력으로 부상**

**협동로봇+AMR 융합 트렌드**
- 협동로봇 시장: 2025년 50.8억 달러 (연 43.5% 성장)
- 이동 가능한 로봇팔, 다기능 모듈형 셀 등장
- 이송과 작업 간 경계 소멸

### 2.4 타겟 시장 세분화

| 시장 | 규모 | 올턴 접근 전략 |
|------|------|--------------|

| **농업용 로봇** | 스마트팜 확대 | 험지 주행 메카넘휠 로봇 |

## 3. 핵심 기술 및 경쟁력

### 3.1 기술 스택

```
┌─────────────────────────────────────────────────┐
│                   ATIDRIVE Stack                │
├─────────────────────────────────────────────────┤
│  AI Layer      │ 객체 인식, 경로 계획, 자율주행   │
│  (Hailo-8/     │ TensorFlow, PyTorch            │
│   Jetson)      │ LiDAR/Camera Fusion            │
├─────────────────────────────────────────────────┤
│  Control Layer │ ROS2 호환, ESP32-S3            │
│                │ JSON 기반 통신 프로토콜          │
│                │ 실시간 모터 제어 (FOC)          │
├─────────────────────────────────────────────────┤
│  Hardware      │ 메카넘휠 자체 설계              │
│  Layer         │ 험지 주행용 특수 휠             │
│                │ RS-485 서보 제어               │
└─────────────────────────────────────────────────┘
```

### 3.2 핵심 경쟁력

| 경쟁력 | 설명 | 차별화 포인트 |
|--------|------|-------------|
| **메카넘휠 자체 설계** | 휠 복원 사업 경험 기반 | 국내 유일 험지용 메카넘휠 설계 |
| **HW+SW 통합 역량** | 전 과정 내재화 | 빠른 커스터마이징, 원가 절감 |
| **AI 제어 기술** | 엔비디아 칩셋 활용 | 엣지 AI 로봇 제어 |
| **프로토타입 보유** | 지게차/고소작업차 | 즉시 상용화 가능 |

### 3.3 기술 로드맵

```
Phase 1 (완료)        Phase 2 (현재)       Phase 3 (진행중)      Phase 4 (목표)
전기 기반 제어   →    디지털 제어    →    AI 통합 제어    →    완전 자율주행
                      ESP32-S3            Hailo-8/Jetson        SLAM + 경로계획
                      USB/JSON 통신        객체 인식              무인 운영
```

### 3.4 지식재산권 및 인증 계획

- 험지전용 메카넘휠 설계 특허 출원 예정 (2026년)

- ROS2 호환 인증

### 8.2 투자 하이라이트

**왜 올턴인가?**

1. **검증된 기술력**
   - 1억원 규모 정부 R&D 수행 중 + 3~5억원 추가 수주 예정
   - 2026년 총 4~6억원 R&D 투자 계획
   - 산업용 프로토타입 보유

2. **성장하는 시장**
   - 국내 AMR 시장 3.5조 → 5조원 (2년 내 43% 성장)
   - AGV → AMR 전환기 진입

3. **정부 정책 수혜**
   - 스마트팩토리, 제조 로봇 지원 확대
   - 물류 첨단화 정책 부합

4. **진입 장벽 구축**
   - 험지전용 메카넘휠: 국내 유일
   - HW+SW 통합 역량: 모방 어려움

5. **확장 가능성**
   - 교육 → 물류 → 농업 → 건설 순차 진출
   - 플랫폼 기반 다양한 응용 가능

3. **산업용 프로토타입** 보유 (즉시 상용화 가능)
4. **정부 R&D 4~6억원** 확보 예정
5. **AMR 시장 43% 성장** 수혜 예상
