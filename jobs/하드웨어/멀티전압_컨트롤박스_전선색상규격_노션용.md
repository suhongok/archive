# 🔌 멀티 전압 컨트롤 박스 전선 색상 규격

> 💡 48V 배터리, 24V 내부 전압, 5V 컨트롤러 전압을 사용하는 컨트롤 박스의 전선 색상 체계

---

## 🎨 추천 색상 체계

| 전압 레벨 | (+) 양극 | (-) 음극 / GND | 비고 |
|-----------|---------|----------------|------|
| **48V** (배터리) | 🔴 **빨강 (Red)** | ⚫ **검정 (Black)** | 주 전원, 가장 굵은 선 |
| **24V** (내부) | 🟠 **주황 (Orange)** | ⚫ **검정 (Black)** | DC-DC 변환 후 |
| **5V** (컨트롤러) | 🟡 **노랑 (Yellow)** | ⚫ **검정 (Black)** | 로직/신호용 |

---

## 📐 설계 원칙

### 1️⃣ 전압 높을수록 "따뜻한" 색 (위험도 순)

- 🔴 48V → 빨강 (가장 위험)
- 🟠 24V → 주황
- 🟡 5V → 노랑 또는 파랑

### 2️⃣ GND 구분

**공통 GND인 경우**

모두 검정, 단 **선경(굵기)으로 구분**

**분리 GND인 경우**

- 48V GND → ⚫ 검정
- 24V GND → 🟤 갈색
- 5V GND → 회색

### 3️⃣ 신호선 색상

| 용도 | 색상 |
|------|------|
| RS-485 A+ | 🔵 파랑 (Blue) |
| RS-485 B- | ⚪ 흰색/파랑 (White-Blue) |
| USB D+ / D- | 🟢 녹색 / ⚪ 흰색 |
| CAN-H / CAN-L | 🟡 노랑 / 🟢 녹색 |
| 비상정지 (E-Stop) | 🔴🟡 **빨강+노랑 줄무늬** 또는 빨강 |

---

## 📏 선경(AWG) 기준

| 용도 | AWG | 비고 |
|------|-----|------|
| 48V 전력선 | 12~14 AWG | 전류량에 따라 |
| 24V 전력선 | 16~18 AWG | |
| 5V / 신호선 | 20~24 AWG | |

---

## 🏷️ 라벨링

> ⚠️ 색상만으로는 부족하므로 반드시 라벨링 병행

- 열수축 튜브에 전압 표기 (예: `48V+`, `24V+`, `5V+`)
- 또는 케이블 마커 사용
- 컨트롤 박스 뚜껑 안쪽에 **색상 범례표** 부착

---

## 🔧 배선 구조

```
[48V 배터리] ──빨강/검정──→ [DC-DC 48→24V] ──주황/검정──→ [24V 부하]
                                                          │
                                              [DC-DC 24→5V] ──노랑/검정──→ [ESP32, 로직]
```

---

## 🛡️ 퓨즈/차단기 배치

- ✅ 각 전압 단마다 퓨즈 설치
- ✅ 48V 입력단에 메인 차단기 필수
