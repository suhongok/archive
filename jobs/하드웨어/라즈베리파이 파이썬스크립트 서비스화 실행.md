# 라즈베리파이 파이썬스크립트 서비스화 실행

> **생성일:** 2024-01-30T07:28:00.000Z
> **수정일:** 2025-09-13T15:38:00.000Z

라즈베리 파이에서 파이썬 스크립트 파일을 서비스화하여 계속 실행하게 하는 방법은 여러 가지가 있습니다. 가장 일반적인 방법 중 하나는 systemd를 사용하는 것입니다. systemd는 Linux 시스템에서 서비스를 관리하는 표준 방법으로, 시스템 부팅 시 자동으로 스크립트를 시작하고, 실패시 재시작하는 등의 기능을 제공합니다.
다음은 systemd를 사용하여 라즈베리 파이에서 파이썬 스크립트를 서비스로 설정하는 방법에 대한 기본적인 단계입니다:
### 1. 파이썬 스크립트 준비

- 먼저, 파이썬 스크립트가 준비되어 있어야 합니다. 이 스크립트는 라즈베리 파이에서 직접 실행할 수 있어야 합니다.
- 스크립트가 실행될 경로를 확인하세요. 예를 들어, /home/pi/myscript.py와 같은 경로일 수 있습니다.
### 2. Systemd 서비스 파일 생성

- /etc/systemd/system 디렉토리에 .service 확장자를 가진 파일을 생성합니다. 예를 들어, myscript.service라고 할 수 있습니다.
- sudo nano /etc/systemd/system/myscript.service 명령어를 사용하여 새 서비스 파일을 생성하고 편집합니다.
### 3. 서비스 파일 내용 작성

- 다음은 서비스 파일의 기본 구조입니다:
- ExecStart에는 파이썬 실행 파일의 경로와 스크립트 파일의 경로를 지정합니다.
- WorkingDirectory는 스크립트가 실행되는 디렉토리입니다.
- User는 스크립트를 실행할 사용자입니다 (대부분의 경우 'pi'입니다).
### 4. 서비스 활성화 및 시작

- 생성한 서비스를 활성화하려면 다음 명령어를 사용합니다: sudo systemctl enable myscript.service
- 서비스를 시작하려면: sudo systemctl start myscript.service
### 5. 서비스 상태 확인

- 서비스가 제대로 실행되고 있는지 확인하려면: sudo systemctl status myscript.service
이러한 단계를 통해 라즈베리 파이에서 파이썬 스크립트를 서비스로 설정할 수 있습니다. 스크립트가 특정 조건에서만 실행되어야 한다면, 서비스 파일에 추가적인 설정을 할 수 있습니다. 예를 들어, 특정 시간에만 실행되게 하거나, 다른 서비스가 시작된 후에 실행되게 설정할 수 있습니다.
