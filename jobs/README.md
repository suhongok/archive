**기술 문서:**
```
[주제]_[상세내용].md
예: ESP32_USB_JSON_통신.md
```

**회의록:**
```
[날짜]_[주제]_회의.md 또는 [기관명]_미팅.md
예: 24년_3월_27일_회의_기록.md
    한국건설기계연구원_미팅.md
```

**프로젝트 문서:**
```
[프로젝트명]_[문서유형].md
```
