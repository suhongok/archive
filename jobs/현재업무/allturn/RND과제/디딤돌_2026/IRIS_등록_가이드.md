# IRIS 등록 가이드 (올턴용)

**마감일**: 2026.01.23 18:00
**예상 소요시간**: 기관등록 1~3일, 연구자등록 1일
**⚠️ 최소 1주일 전 완료 권장**

---

## 1. 등록 순서 개요

```
[1단계] 회원가입 → [2단계] 기관등록 → [3단계] 연구자등록 → [4단계] 과제신청
        (즉시)       (1~3일 승인)       (즉시~1일)         (기관승인 후)
```

---

## 2. 1단계: IRIS 회원가입

### 접속
- **URL**: https://www.iris.go.kr
- 우측 상단 "회원가입" 클릭

### 가입 유형
- **연구자** 선택 (대표이사 또는 연구책임자)

### 필요 정보
| 항목 | 준비물 |
|------|--------|
| 본인인증 | 휴대폰 또는 공동인증서 |
| 이메일 | 업무용 이메일 |
| 연락처 | 휴대폰 번호 |

---

## 3. 2단계: 기관 등록 ⭐ 가장 중요

### 3.1 기관등록 신청 경로
```
로그인 → 상단메뉴 "기관관리" → "기관등록신청" → "신규기관등록"
```

### 3.2 필요 서류

| 서류명 | 파일형식 | 비고 |
|--------|----------|------|
| 사업자등록증 사본 | PDF/JPG | 필수 |
| 법인등기부등본 | PDF | 법인인 경우 |
| 대표자 신분증 사본 | PDF/JPG | 필요시 |

### 3.3 입력 정보

**기관 기본정보**
| 항목 | 올턴 입력값 |
|------|------------|
| 기관명 | (주)올턴 또는 올턴 |
| 사업자등록번호 | (올턴 사업자번호) |
| 법인등록번호 | (법인인 경우) |
| 대표자명 | (대표이사명) |
| 설립일 | 2023년 (정확한 날짜) |
| 업종 | 제조업 / 기계장비 제조 |
| 기업규모 | 중소기업 |

**기관 주소정보**
| 항목 | 입력값 |
|------|--------|
| 소재지 | 전북특별자치도 전주시 ... |
| 우편번호 | (올턴 우편번호) |
| 전화번호 | (대표번호) |

**기관 총괄담당자** (중요!)
- 기관의 R&D 과제 신청을 총괄하는 담당자
- 보통 대표이사 또는 연구책임자 지정
- 이 담당자가 과제 제출 권한을 가짐

### 3.4 승인 대기
- 신청 후 **1~3 영업일** 소요
- 승인 완료 시 이메일/SMS 알림
- ⚠️ **서류 미비 시 반려될 수 있음** → 즉시 재신청

---

## 4. 3단계: 연구자 등록 (NRI 발급)

### 4.1 연구자 전환 신청
```
로그인 → 마이페이지 → "연구자전환신청"
```

### 4.2 NRI(국가연구자번호) 발급
- 연구자 전환 완료 시 자동 발급
- 연구개발계획서에 기재 필요

### 4.3 연구자 정보 등록 (필수!)

**학력사항**
| 항목 | 입력 예시 |
|------|----------|
| 최종학력 | 학사/석사/박사 |
| 학교명 | OO대학교 |
| 전공 | 기계공학/전자공학 등 |
| 졸업년월 | YYYY.MM |

**경력사항**
| 항목 | 입력 예시 |
|------|----------|
| 근무기관 | (주)올턴 |
| 직위 | 대표이사/연구원 |
| 담당업무 | 메카넘휠 로봇 개발 |
| 근무기간 | 2023.01 ~ 현재 |

**주요 연구실적** (선택, 가점 요소)
- 특허 출원/등록 이력
- 논문 게재 이력
- 이전 연구과제 수행 이력

---

## 5. 4단계: 과제 신청 준비

### 5.1 신청 가능 조건 확인
- [ ] 기관등록 **승인 완료**
- [ ] 연구자등록 **완료** (NRI 발급)
- [ ] 기관 총괄담당자로 **지정됨**

### 5.2 과제 신청 경로
```
로그인 → "R&D신청" → "사업공고" → "디딤돌" 검색 → "전북지방청" 선택 → "신청"
```

### 5.3 신청 시 필요 파일

| 서류 | 양식 | 비고 |
|------|------|------|
| 연구개발계획서 | HWP (지정양식) | 20페이지 이내 |
| 사업자등록증 | PDF | 필수 |
| 중소기업확인서 | PDF | 필수 |
| 재무제표 | PDF | 최근 2개년 |
| 신용조회동의서 | HWP (지정양식) | 필수 |
| 개인정보동의서 | HWP (지정양식) | 필수 |
| 가점증빙자료 | PDF | 해당시 |

## 7. 자주 발생하는 문제

### 문제 1: 기관등록 반려
**원인**: 서류 미비, 정보 불일치
**해결**: 반려 사유 확인 → 서류 보완 → 재신청

### 문제 2: 연구자 전환 불가
**원인**: 기관등록 미완료
**해결**: 기관등록 승인 후 재시도

### 문제 3: 과제신청 버튼 비활성화
**원인**: 기관 총괄담당자 미지정
**해결**: 기관관리 → 담당자 지정 확인

### 문제 4: 파일 업로드 오류
**원인**: 파일 용량 초과, 형식 오류
**해결**: PDF 압축, HWP 재저장
