## 2. 연구개발 필요성

### 2.1 문제 정의

#### 기존 메카넘휠의 한계
```
문제 1: 실내 환경 제한
├── 기존 메카넘휠은 평탄한 실내 바닥 전용
├── 험지(흙, 자갈, 경사면)에서 접지력 저하
├── 슬립 및 자세 불안정 문제 발생
└── 옥외 활용 불가

문제 2: 단순 제어 방식
├── 고정된 속도/토크 제어
├── 지형 변화에 적응 불가
├── 에너지 효율 저하
└── 안전성 문제

문제 3: AI 미적용
├── 환경 인식 없이 맹목적 주행
├── 장애물 대응 불가
├── 인간-로봇 협업 제한
└── 자율주행 기능 부재
```

#### 시장 수요
| 시장 | 현황 | 성장 전망 |
|------|------|----------|
| 국내 AMR/AGV | 3.5조원 (2025) | 12.4조원 (2031) |
| 교육용 로봇 | 급성장 중 | 연 15% 성장 |
| 스마트팜 로봇 | 초기 시장 | 블루오션 |

### 2.2 기술적 배경

#### Physical AI란?
```
┌─────────────────────────────────────────────────────────────┐
│                   Physical AI 개념                           │
├─────────────────────────────────────────────────────────────┤
│  기존 AI: 인식 → 판단 → 명령 (소프트웨어 중심)               │
│                                                             │
│  Physical AI: 인식 → 판단 → 물리적 상호작용                 │
│               (하드웨어 + 소프트웨어 통합)                   │
│                                                             │
│  핵심 기능:                                                 │
│  ├── 지형 적응: 실시간 지면 분석 → 휠 토크 조절             │
│  ├── 슬립 예측: 미끄러짐 사전 감지 → 선제적 보정            │
│  ├── 자세 안정화: IMU + 카메라 → 자동 밸런싱               │
│  └── 상황 인식: VLM 기반 환경 이해                         │
└─────────────────────────────────────────────────────────────┘
```

#### 메카넘휠 기술의 장점
- **360도 전방향 이동**: 전진, 후진, 측면, 대각선, 제자리 회전
- **제자리 회전**: 회전반경 0m (일반 지게차 2.5~3m)
- **공간 효율**: 협소 공간에서 40% 이상 공간 절약
- **정밀 위치 제어**: ±2mm 정밀도 가능

## 3. 연구개발 목표

### 3.1 최종 목표

> **Physical AI를 탑재한 175mm급 소형 험지 적응형 메카넘휠 플랫폼 개발**
>
> 지형을 스스로 인식하고, 슬립을 예측하며, 실시간으로 토크를 조절하는
> 지능형 메카넘휠 로봇 플랫폼 개발

### 3.2 정량적 목표 (175mm급)

| 지표 | 기존 기술 | 개발 목표 | 측정 방법 |
|------|----------|----------|----------|
| **휠 직경** | 300mm+ | **175mm** | 실측 |
| **장애물 극복 (전/후)** | 1cm | **2.5cm** | 실측 |
| **장애물 극복 (좌/우)** | 0.5cm | **1.5cm** | 실측 |
| **경사 주행** | 5° | **10°** | 경사로 테스트 |
| **적재 용량** | 30kg | **60~100kg** | 하중 테스트 |
| **주행 속도** | 2km/h | **3km/h** | 실측 |
| **AI 지형 인식률** | - | **95%** | 테스트셋 |
| **슬립 예측 정확도** | - | **90%** | 실험 |
| **토크 보정 응답시간** | - | **50ms 이내** | 측정 |

### 3.3 정성적 목표

1. **Physical AI 지형 적응 시스템** 국내 최초 상용화
2. **ROS2 호환** 통신 프로토콜 표준화
3. **교육용/산업용** 범용 플랫폼 설계
4. **국내 중소기업** 맞춤형 저가격 솔루션

### 4.2 세부 개발 내용

#### 1단계: 175mm급 험지 메카넘휠 개발 (1~4개월)

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 휠 설계 | 175mm 직경 최적화 설계 | 3D 모델, 도면 |
| 고마찰 롤러 | 험지용 고마찰 소재 적용 | 롤러 시제품 |
| 서스펜션 | 소형 서스펜션 구조 설계 | 서스펜션 모듈 |
| 센서 통합 | IMU, 카메라, 거리센서 연동 | 센서 보드 |
| 모터 제어 | ESP32-S3 USB NDJSON 통신 | 펌웨어 v1.0 |

**메카넘휠 역기구학 공식:**
```
FL = linear_x + linear_y + angular_z
FR = linear_x - linear_y - angular_z
RL = linear_x - linear_y + angular_z
RR = linear_x + linear_y - angular_z

(FL: 전방좌, FR: 전방우, RL: 후방좌, RR: 후방우)
```

## 11. 기존 사업과의 차별성

### JBTP 사업 vs 본 IRIS 사업

| 구분 | JBTP 사업 (기진행) | 본 IRIS 사업 (신규) |
|------|-------------------|-------------------|
| **초점** | 험지 메카넘휠 **하드웨어** | **Physical AI** + 플랫폼 |
| **휠 크기** | 350mm급 (산업용) | **175mm급** (소형/교육용) |
| **적재 용량** | 250kg | **60~100kg** |
| **장애물 극복** | 5cm | **2.5cm** |
| **AI 기능** | 없음 | **Physical AI 핵심** |
| **타겟 시장** | 산업용 지게차/고소작업대 | **교육용/스마트팜** |
| **협력기관** | 한국건설기계연구원 | 단독 (또는 대학 연계) |

### 기술적 차별점

1. **Physical AI 핵심 개발**
   - JBTP: 하드웨어(휠, 서스펜션) 중심
   - IRIS: 소프트웨어(AI, 알고리즘) 중심

2. **소형화/경량화**
   - 350mm → 175mm (절반 크기)
   - 교육용/연구용 최적화

3. **시장 타겟 분리**
   - JBTP: 건설/물류 산업용
   - IRIS: 교육/스마트팜

## 부록: 1페이지 요약 (Executive Summary)

---

### 과제명
**Physical AI 기반 험지 적응형 메카넘휠 플랫폼 개발**

### 문제
- 기존 메카넘휠은 **평탄한 실내** 전용, 험지 대응 불가
- 단순 제어로 **지형 적응 불가**, 슬립 및 불안정 문제
- AI 미적용으로 **자율 주행/안전 기능** 부재

### 목표 (175mm급)
| 지표 | 목표 |
|------|------|
| 장애물 극복 (전/후) | **2.5cm** |
| 경사 주행 | **10°** |
| AI 지형 인식률 | **95%** |
| 슬립 예측 정확도 | **90%** |

### 핵심 기술
- **Physical AI**: 지형 인식 → 슬립 예측 → 토크 보정
- **175mm 소형 험지 휠**: 고마찰 롤러 + 서스펜션
- **범용 플랫폼**: ROS2 호환, ESP32-S3 USB NDJSON

### 왜 올턴인가?
1. **350mm 험지 휠 개발 완료** (JBTP 사업)
2. **Hailo-8/Jetson AI 통합 경험** 보유
3. **메카넘 프로토타입** 다수 보유
4. **Physical AI** 기술 방향 확립
