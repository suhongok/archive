## 1. 기술개발 목표 (최대 1페이지)

### 1.1 최종 개발 목표

> **Physical AI 기반 스마트팜 자율운반 메카넘 로봇 (ATOM-Farm)**
>
> GPS로 목적지를 자율 이동하고, Physical AI로 지형을 인식하여 속도를 자동 조절하며,
> 장애물/경사를 감지하여 안전하게 운행하는 스마트팜 전용 운반 로봇 개발

### 1.2 핵심 기능 (4가지)

| 기능 | 설명 | 센서 |
|------|------|------|
| **GPS 기반 자율 이동** | 비닐하우스 ↔ 집하장 자동 왕복 | GPS (RTK 또는 일반) |
| **장애물 감지** | 전방 장애물 감지 → 정지/회피 | Depth 카메라 |
| **경사 감지** | 경사 감지 → 감속/정지 (전복 방지) | IMU |
| **지형 인식 속도 조절** | 지형 분류 → 자동 속도 조절 **(Physical AI 핵심)** | 카메라 + AI |

### 1.3 정량적 개발 지표

| 지표 | **개발 목표** | 측정 방법 |
|------|--------------|----------|
| GPS 목적지 도달 정확도 | **±50cm** | GPS 좌표 비교 |
| 장애물 감지 거리 | **1m 이상** | Depth 카메라 측정 |
| 경사 감지 정확도 | **±2°** | IMU 측정 |
| 지형 인식률 (3종) | **90%** | 테스트셋 평가 |
| 자율주행 성공률 (100m 코스) | **95%** | 실증 테스트 |
| 적재 용량 | **60~100kg** | 하중 테스트 |
| 주행 속도 | **3km/h** | 실측 |
| 1회 충전 주행거리 | **5km 이상** | 실측 |

### 1.4 정성적 개발 목표

1. **Physical AI 지형 적응 속도 제어** 국내 최초 스마트팜 적용
2. **GPS 기반 자율 이동 시스템** 구현
3. **ROS2 호환** 통신 프로토콜 표준화
4. **저가형 솔루션** 제공 (500~800만원, 기존 대비 50% 이하)

## 2. 연구개발 방법 (최대 4페이지)

### 2.1 기술 개발 범위

```
┌─────────────────────────────────────────────────────────────┐
│                    개발 범위 (Scope)                         │
├─────────────────────────────────────────────────────────────┤
│  [하드웨어 계층]                                             │
│  ├── 175mm급 소형 메카넘휠 플랫폼                           │
│  ├── ESP32-S3 기반 모터 제어 보드 (RPM 제어)                │
│  ├── GPS 모듈 (RTK 또는 일반)                               │
│  └── 센서 통합 (Depth 카메라, IMU, 엔코더)                  │
│                                                             │
│  [Physical AI 계층]                                         │
│  ├── Raspberry Pi 5 + Hailo-8 (26 TOPS)                    │
│  ├── 지형 인식 모델 (3종: 포장/비포장/잔디)                 │
│  ├── 장애물 감지 알고리즘                                   │
│  ├── 경사 감지 및 안전 제어                                 │
│  └── 속도 자동 조절 시스템                                  │
│                                                             │
│  [자율주행 계층]                                             │
│  ├── GPS 기반 경로 계획 및 이동                             │
│  ├── 목적지 설정 및 왕복 운행                               │
│  ├── USB NDJSON 통신 프로토콜                               │
│  └── ROS2 인터페이스                                        │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 센서 구성

| 센서 | 용도 | 예상 비용 |
|------|------|----------|
| **GPS (RTK 또는 일반)** | 목적지 이동, 위치 추정 | 50~200만원 |
| **Depth 카메라 (RealSense D435)** | 장애물 감지, 지형 인식 | 50만원 |
| **IMU (MPU9250)** | 경사 감지, 자세 측정 | 5만원 |
| **휠 엔코더** | 주행 거리, 속도 측정 | 포함 |

### 2.3 단계별 개발 내용

#### **1단계: 175mm 휠 플랫폼 + 센서 통합 (1~4개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 플랫폼 구성 | 175mm 메카넘휠 플랫폼 조립 | 완성 플랫폼 |
| GPS 통합 | GPS 모듈 연동 및 위치 측정 | GPS 인터페이스 |
| 센서 통합 | Depth 카메라, IMU 연동 | 센서 드라이버 |
| 모터 제어 | ESP32-S3 USB NDJSON, RPM 제어 | 펌웨어 v1.0 |
| GPS 이동 | 목적지 좌표 입력 → 자율 이동 | GPS 네비게이션 SW |

**R&D 검증 방법:**
- **GPS 정확도**: 정해진 좌표로 이동 → 도착 오차 ±50cm 이내 확인
- **센서 연동**: 모든 센서 데이터 실시간 수신 확인 (10Hz 이상)
- **기본 주행**: 100m 직선 주행 테스트 통과

#### **2단계: Physical AI 개발 (5~8개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| AI 플랫폼 구축 | RPi5 + Hailo-8 환경 구성 | HW/SW 통합 환경 |
| 지형 인식 모델 | 카메라 기반 3종 지면 분류 (포장/비포장/잔디) | 학습 모델 (.onnx) |
| 장애물 감지 | Depth 카메라 기반 전방 장애물 감지 | 장애물 감지 SW |
| 경사 감지 | IMU 기반 경사 감지 및 안전 제어 | 경사 감지 SW |
| 속도 조절 | 지형 인식 결과 → 자동 속도 조절 | 적응형 속도 제어 SW |

**Physical AI 핵심 로직:**
```
┌─────────────────────────────────────────────────────────────┐
│              Physical AI 지형 적응 속도 제어                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   [입력]                 [처리]               [출력]         │
│                                                             │
│   ┌─────────┐      ┌─────────────┐      ┌─────────────┐    │
│   │ 카메라   │─────▶│             │      │             │    │
│   └─────────┘      │  Hailo-8    │      │  속도 조절   │    │
│                    │  지형 인식   │─────▶│  100%/70%/50%│    │
│                    │  (3종 분류)  │      │             │    │
│                    └─────────────┘      └─────────────┘    │
│                                                             │
│   지형별 속도 설정:                                          │
│   ├── 포장도로: 100% (최대 속도)                            │
│   ├── 비포장(흙): 70%                                       │
│   └── 잔디/풀: 50%                                          │
│                                                             │
│   ┌─────────┐      ┌─────────────┐      ┌─────────────┐    │
│   │ Depth   │─────▶│ 장애물 감지  │─────▶│ 정지/회피    │    │
│   │ 카메라   │      │ (1m 이내)   │      │             │    │
│   └─────────┘      └─────────────┘      └─────────────┘    │
│                                                             │
│   ┌─────────┐      ┌─────────────┐      ┌─────────────┐    │
│   │ IMU     │─────▶│ 경사 감지   │─────▶│ 감속/정지    │    │
│   └─────────┘      │ (10° 이상)  │      │ (전복 방지)  │    │
│                    └─────────────┘      └─────────────┘    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**R&D 검증 방법:**
- **지형 인식 정확도**: 3종 지형 × 100장 테스트셋 → 90% 이상 정확도
- **장애물 감지**: 1m 거리에서 장애물(사람, 상자 등) 감지 성공률 99%
- **경사 감지**: 0°~15° 경사면에서 ±2° 오차 이내 측정
- **속도 조절**: 지형 변화 시 2초 이내 속도 변경 확인

#### **3단계: 플랫폼 통합 및 스마트팜 실증 (9~12개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 플랫폼 통합 | 모든 기능 통합 테스트 | 완성 플랫폼 2대 |
| ROS2 연동 | nav2 연동, 원격 모니터링 | ROS2 패키지 |
| 실내 테스트 | 기능/성능 검증 | 테스트 보고서 |
| 스마트팜 실증 | 비닐하우스/농로 실제 운행 | 실증 결과서 |
| 문서화 | 사용자 매뉴얼, API 문서 | 기술 문서 세트 |

**R&D 검증 방법:**
- **자율주행 성공률**: 100m 코스 10회 운행 → 성공률 95% 이상
- **왕복 운행**: 비닐하우스 ↔ 집하장 (50m) 자동 왕복 테스트
- **적재 테스트**: 60kg, 80kg, 100kg 단계별 하중 테스트
- **Physical AI 동작**: 지형 변화 시 실시간 속도 조절 확인 (로그 분석)

### 2.4 개발 환경

| 구분 | 사양/도구 |
|------|----------|

### 3.2 선행연구개발 결과 활용계획 (최대 2페이지)

| **핵심 초점** | **하드웨어** (휠, 서스펜션) | **소프트웨어** (GPS 자율주행 + Physical AI) |
| **휠 크기** | 350mm급 (산업용 대형) | **175mm급 (소형/스마트팜용)** |

| **자율주행** | 없음 (수동 조작) | **GPS 기반 자율 이동** |
| **타겟 시장** | 산업용 지게차/고소작업대 | **스마트팜 자율운반 로봇** |

| **제어 방식** | 토크 제어 | **RPM(속도) 제어** |

#### 활용 계획

**1. 하드웨어 설계 기술 활용**

JBTP 사업에서 개발한 350mm급 휠 설계 기술을 175mm급으로 스케일다운:
- 롤러 배열 최적화 노하우 적용
- 고마찰 소재 배합 기술 활용

**2. 제어 시스템 공유**

기 개발된 ESP32-S3 USB NDJSON 통신 프로토콜 그대로 적용:
```json
{"cmd": "vel", "linear_x": 0.5, "linear_y": 0.0, "angular_z": 0.3}
```
- 메카넘휠 역기구학 공식 동일 적용
- 모터 제어 펌웨어 재사용 (토크 제어 → RPM 제어 확장)

## 9. 지방청 특화지표 검토 자료

### 9.1 특화분야 적합성 (최대 1페이지)

#### 해당 특화분야: **특수목적용지능형 기계부품**

**적합성 설명:**

본 과제에서 개발하는 **Physical AI 기반 스마트팜 자율운반 메카넘 로봇**은 다음과 같은 이유로 **특수목적용지능형 기계부품**에 해당합니다:

| 특화분야 요건 | 본 과제 적합성 |
|---------------|---------------|
| **특수목적** | 스마트팜 전용 자율운반 로봇 (비포장 농로 대응) |
| **지능형** | Physical AI 기반 자율 지형 적응 + GPS 자율주행 |
| **기계부품** | 메카넘휠 구동 모듈 (롤러, 모터, 센서 통합) |

**핵심 기술:**
- **Physical AI**: 지형 인식 → 속도 자동 조절
- **GPS 자율주행**: 목적지 자동 이동
- **안전 시스템**: 장애물 감지, 경사 감지

### 9.2 시급성 (지역 현안 연계) (최대 1페이지)

#### 해당 지역 현안: **건설기계** + **농업 인력 부족**

**연계성 설명:**

전북 지역은 **한국건설기계연구원**이 위치한 국내 건설기계 연구의 중심지이며, 동시에 **농업 비중이 높은 지역**으로 **농업 인력 부족** 문제가 심각합니다.

| 연계 항목 | 내용 |
|----------|------|
| **건설기계 협력** | JBTP 사업에서 한국건설기계연구원과 350mm 험지휠 공동개발 중 |
| **농업 인력 부족** | 전북 농업 종사자 평균 연령 65세+, 청년 농업 기피 |
| **기술 확장성** | 본 과제의 Physical AI 기술 → 건설기계 자율화에 적용 가능 |

**시급성 근거:**
- 농촌 인구 감소 및 고령화 심화
- 단순 반복 운반 작업의 자동화 필요
- 저가형 자율로봇 부재 (중소 농가 접근 불가)
