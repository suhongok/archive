## 지원 자격

### 필수 조건 (모두 충족 필요)
- [ ] **업력**: 7년 이하 (올턴: 2023년 설립, **적합**)
- [ ] **매출액**: 20억원 미만 (**확인 필요**)
- [ ] **중기부 R&D**: 처음 수행하는 기업 (**확인 필요** - 현재 1억원 과제가 중기부인지)
- [ ] **중소기업**: 「중소기업기본법」 제2조 해당 (**적합**)

## 신청 방법

### 1단계: 사전 준비
- [ ] IRIS 회원가입 (www.iris.go.kr)
- [ ] 기관 등록 (사업자등록증 기준)
- [ ] 연구책임자 등록

### 2단계: 온라인 신청
- **신청 포털**: 범부처통합연구지원시스템 (IRIS)
- **URL**: https://www.iris.go.kr
- **신청기간**: 2026.01.06 ~ 2026.01.23

### 3단계: 제출 서류
- [ ] 사업계획서 (IRIS 양식)
- [ ] 기술개발계획서
- [ ] 재무제표 (최근 2개년)
- [ ] 사업자등록증 사본
- [ ] 기타 증빙서류
