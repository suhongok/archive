## 1. 기술개발 목표 (최대 1페이지)

### 1.1 최종 개발 목표

> **Physical AI 기반 175mm급 소형 험지 메카넘휠 + 지형 적응 제어 플랫폼**
>
> 지형을 스스로 인식하고, 슬립을 예측하며, 실시간으로 토크를 조절하는
> 지능형 메카넘휠 로봇 플랫폼 개발

### 1.2 정량적 개발 지표

| 지표 | 기존 기술 | **개발 목표** | 측정 방법 |
|------|----------|--------------|----------|
| 휠 직경 | 300mm+ | **175mm** | 실측 |
| 장애물 극복 (전/후) | 1cm | **2.5cm** | 단차 테스트 |
| 장애물 극복 (좌/우) | 0.5cm | **1.5cm** | 단차 테스트 |
| 경사 주행 | 5° | **10°** | 경사로 테스트 |
| 적재 용량 | 30kg | **60~100kg** | 하중 테스트 |
| 주행 속도 | 2km/h | **3km/h** | 실측 |
| AI 지형 인식률 | - | **95%** | 5종 지형 테스트셋 평가 |
| 슬립 예측 정확도 | - | **90%** | 실험 데이터 분석 |
| 토크 보정 응답시간 | - | **50ms 이내** | 시스템 로그 측정 |

### 1.3 정성적 개발 목표

1. **Physical AI 지형 적응 시스템** 국내 최초 상용화
2. **ROS2 호환** 통신 프로토콜 표준화
3. **교육용/산업용** 범용 플랫폼 설계
4. **국내 중소기업** 맞춤형 저가격 솔루션 제공

## 2. 연구개발 방법 (최대 4페이지)

### 2.1 기술 개발 범위

```
┌─────────────────────────────────────────────────────────────┐
│                    개발 범위 (Scope)                         │
├─────────────────────────────────────────────────────────────┤
│  [하드웨어 계층]                                             │
│  ├── 175mm급 소형 험지 메카넘휠                             │
│  ├── 고마찰 롤러 + 소형 서스펜션 구조                       │
│  ├── ESP32-S3 기반 모터 제어 보드                           │
│  └── 센서 통합 (IMU, 카메라, 엔코더)                        │
│                                                             │
│  [Physical AI 계층]                                         │
│  ├── NVIDIA Jetson / Raspberry Pi 5 + Hailo-8              │
│  ├── 지형 인식 모델 (딥러닝)                                │
│  ├── 슬립 예측 알고리즘                                     │
│  ├── 적응형 토크 제어                                       │
│  └── VLM 기반 상황 인식                                     │
│                                                             │
│  [플랫폼 계층]                                               │
│  ├── USB NDJSON 통신 프로토콜                               │
│  ├── ROS2 인터페이스                                        │
│  ├── 범용 플랫폼 프레임                                     │
│  └── 사용자 제어 인터페이스                                 │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 단계별 개발 내용

#### **1단계: 175mm급 험지 메카넘휠 개발 (1~4개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 휠 설계 | 175mm 직경 최적화 설계, FEM 해석 | 3D 모델, 설계도면 |
| 고마찰 롤러 | 험지용 TPU 고마찰 소재 적용 | 롤러 시제품 |
| 서스펜션 | 소형 독립 서스펜션 구조 설계 | 서스펜션 모듈 |
| 센서 통합 | IMU, 카메라, 거리센서 연동 | 통합 센서 보드 |
| 모터 제어 | ESP32-S3 USB NDJSON 통신 구현 | 펌웨어 v1.0 |

**R&D 검증 방법:**
- **휠 구조 강도**: FEM 시뮬레이션 + 실물 하중 테스트 (100kg 기준)
- **롤러 마찰계수**: 재질별 마찰계수 측정 (흙, 자갈, 콘크리트)
- **서스펜션 작동**: 충격흡수 테스트 (20mm 단차 통과 시 진동 측정)

#### **2단계: Physical AI 개발 (5~8개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| AI 플랫폼 구축 | Jetson Orin / RPi5 + Hailo-8 환경 구성 | HW/SW 통합 환경 |
| 지형 인식 모델 | 카메라 기반 5종 지면 분류 (흙, 자갈, 콘크리트, 잔디, 타일) | 학습 모델 (.onnx) |
| 슬립 예측 | IMU + 휠 속도 기반 슬립 예측 알고리즘 | 예측 SW 모듈 |
| 토크 보정 | 지형/슬립 정보 기반 실시간 토크 제어 | 제어 SW |
| VLM 통합 | 자연어 명령 처리 (옵션) | VLM 인터페이스 |

**R&D 검증 방법:**
- **지형 인식 정확도**: 5종 지형 × 100장 테스트셋 → 95% 이상 정확도
- **슬립 예측 정확도**: 실제 슬립 vs 예측 비교 (MSE 기준 90% 이상)
- **토크 보정 응답시간**: 지형 변화 감지 → 토크 조절 완료까지 50ms 이내

**Physical AI 시스템 아키텍처:**
```
┌─────────────────────────────────────────────────────────────┐
│              Physical AI 지형 적응 시스템                     │
├─────────────────────────────────────────────────────────────┤
│   [센서 입력]          [AI 처리]           [제어 출력]        │
│                                                             │
│   ┌─────────┐      ┌─────────────┐      ┌─────────────┐    │
│   │ 카메라   │─────▶│             │      │ 휠별 토크    │    │
│   └─────────┘      │   Jetson/   │      │ 개별 제어    │    │
│   ┌─────────┐      │   Hailo-8   │─────▶│             │    │
│   │ IMU     │─────▶│             │      └─────────────┘    │
│   └─────────┘      │  + AI모델   │      ┌─────────────┐    │
│   ┌─────────┐      │             │─────▶│ 자세 보정    │    │
│   │ 엔코더   │─────▶│             │      └─────────────┘    │
│   └─────────┘      └─────────────┘                         │
│                           │                                │
│                    ┌──────┴──────┐                         │
│                    │ 지형 인식    │                         │
│                    │ 슬립 예측    │                         │
│                    │ 토크 최적화  │                         │
│                    └─────────────┘                         │
└─────────────────────────────────────────────────────────────┘
```

#### **3단계: 플랫폼 통합 및 실증 (9~12개월)**

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 플랫폼 조립 | 휠 + AI + 프레임 통합 | 완성 플랫폼 2대 |
| ROS2 연동 | nav2, slam_toolbox 연동 | ROS2 패키지 |
| 실내 테스트 | 정밀도, 속도, 안정성 검증 | 테스트 보고서 |
| 험지 테스트 | 흙, 자갈, 경사면 실증 | 실증 결과서 |
| 문서화 | 사용자 매뉴얼, API 문서 | 기술 문서 세트 |

**R&D 검증 방법:**
- **장애물 극복 (전/후)**: 2.5cm 단차 10회 통과 테스트 → 성공률 100%
- **장애물 극복 (좌/우)**: 1.5cm 단차 10회 옆으로 이동 테스트 → 성공률 100%
- **경사 주행**: 10° 경사로 등반/하강 테스트 → 슬립 없이 주행
- **적재 용량**: 60kg, 80kg, 100kg 단계별 하중 테스트
- **Physical AI 동작**: 지형 변화 시 실시간 토크 조절 확인 (로그 분석)

### 3.2 선행연구개발 결과 활용계획 (최대 2페이지)

#### JBTP 사업과 본 IRIS 사업의 차별성

| 구분 | **JBTP 사업** (기진행) | **본 IRIS 사업** (신규) |
|------|----------------------|----------------------|
| **핵심 초점** | 하드웨어 (휠, 서스펜션) | **소프트웨어 (Physical AI)** |
| **휠 크기** | 350mm급 (산업용 대형) | **175mm급 (소형/교육용)** |
| **적재 용량** | 250kg | **60~100kg** |
| **장애물 극복** | 5cm (전/후) | **2.5cm** (소형화로 인한 조정) |
| **AI 기능** | 없음 (순수 기구 개발) | **Physical AI 핵심** |
| **타겟 시장** | 산업용 지게차/고소작업대 | **교육용/스마트팜** |
| **가격대** | 3,000~5,000만원 | **500~1,200만원** |
| **협력기관** | 한국건설기계연구원 | 단독 (또는 대학 연계) |

#### 활용 계획

**1. 하드웨어 설계 기술 활용**

JBTP 사업에서 개발한 350mm급 휠 설계 기술을 175mm급으로 스케일다운:
- 롤러 배열 최적화 노하우 적용
- 고마찰 소재 배합 기술 활용
- 서스펜션 구조 경량화 설계

**2. 제어 시스템 공유**

기 개발된 ESP32-S3 USB NDJSON 통신 프로토콜 그대로 적용:
```json
{"cmd": "vel", "linear_x": 0.5, "linear_y": 0.0, "angular_z": 0.3}
```
- 메카넘휠 역기구학 공식 동일 적용
- 모터 제어 펌웨어 재사용

## 9. 지방청 특화지표 검토 자료

### 9.1 특화분야 적합성 (최대 1페이지)

#### 해당 특화분야: **특수목적용지능형 기계부품**

**적합성 설명:**

본 과제에서 개발하는 **Physical AI 기반 175mm급 험지 메카넘휠**은 다음과 같은 이유로 **특수목적용지능형 기계부품**에 해당합니다:

| 특화분야 요건 | 본 과제 적합성 |
|---------------|---------------|
| **특수목적** | 험지 환경(흙, 자갈, 경사) 전용 설계 |
| **지능형** | Physical AI 기반 자율 지형 적응 제어 |
| **기계부품** | 메카넘휠 구동 모듈 (롤러, 서스펜션, 모터 통합) |

**핵심 기술:**
- **Physical AI**: 지형 인식 → 슬립 예측 → 토크 보정 자동화
- **지능형 제어**: 기존 단순 제어 → AI 기반 실시간 적응 제어
- **센서 융합**: 카메라 + IMU + 엔코더 통합 처리

**기존 메카넘휠과의 차이:**
- 기존: 평탄한 실내 전용, 단순 속도/방향 제어
- 본 제품: 험지 대응, AI 기반 지형 적응형 토크 제어

### 9.2 시급성 (지역 현안 연계) (최대 1페이지)

#### 해당 지역 현안: **건설기계**

**연계성 설명:**

전북 지역은 **한국건설기계연구원**이 위치한 국내 건설기계 연구의 중심지입니다. 본 과제는 다음과 같이 건설기계 분야와 직접 연계됩니다:

| 연계 항목 | 내용 |
|----------|------|
| **협력 경험** | JBTP 사업에서 한국건설기계연구원과 350mm 험지휠 공동개발 중 |
| **기술 확장성** | 본 과제의 Physical AI 기술 → 건설기계 자율화에 적용 가능 |
| **시장 연계** | 건설 현장용 소형 운반로봇 → 건설기계 보조 장비 시장 |

**건설기계 분야 적용 시나리오:**
```
Physical AI 메카넘휠 기술의 건설기계 확장

1단계: 본 과제 (175mm 소형 플랫폼)
├── 교육용/연구용 플랫폼 개발
├── Physical AI 지형 적응 기술 확보
└── 기술 검증 완료

2단계: JBTP 연계 (350mm 산업용)
├── 건설기계연구원 협력 지속
├── Physical AI → 산업용 적용
└── 고소작업대, 지게차 탑재

3단계: 건설 현장 자율화 (미래)
├── 자율주행 건설 운반로봇
├── 험지 환경 대응 AGV
└── 전북 건설기계 산업 경쟁력 강화
```

**시급성 근거:**
- 건설 현장 인력 부족 심화 (고령화, 위험 기피)
- 험지 대응 자율로봇 기술 수요 급증
- 전북 지역 건설기계 클러스터 활용 필요
