## 다운로드 방법

### Step 1: IRIS 로그인
1. https://www.iris.go.kr 접속
2. 회원가입 또는 로그인
3. 기관 등록 확인

### Step 2: 사업공고 검색
1. 상단 메뉴 → "R&D 신청" → "사업공고"
2. 검색어: "디딤돌" 또는 "창업성장기술개발"
3. 올턴 소재지 해당 지방청 공고 선택

### Step 3: 첨부파일 다운로드
1. 공고 상세 페이지 접속
2. 하단 "첨부파일" 섹션
3. 개별 다운로드 또는 전체 다운로드

### Step 4: 파일 저장
다운로드한 파일을 아래 경로에 저장:
```
/Users/a/Documents/archive/jobs/현재업무/allturn/RND과제/디딤돌_2026/공고문/
```
