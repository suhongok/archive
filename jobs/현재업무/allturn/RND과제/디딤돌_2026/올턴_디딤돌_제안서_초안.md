## 2. 연구개발 필요성

### 2.1 문제 정의

#### 현장 문제점
```
문제 1: 협소 공간에서의 이동 효율성 저하
├── 기존 지게차 회전반경: 평균 2.5~3m
├── 창고 통로 폭 필요: 최소 3.5m
├── 공간 손실률: 약 40%
└── 물류창고 건설 비용 증가

문제 2: 산업현장 충돌 사고
├── 연간 지게차 사고: 약 2만건 (산업안전보건공단)
├── 사망사고: 연 50건 이상
├── 주요 원인: 후진 시 시야 확보 불가, 회전 시 충돌
└── 사회적 비용: 연 수천억원

문제 3: 기존 AMR의 한계
├── 정해진 경로만 이동 (AGV)
├── 전방향 이동 불가
├── 험지/비포장 주행 불가
└── 고가격 (수천만원~수억원)
```

#### 수요 근거
| 시장 | 현황 | 성장 전망 |
|------|------|----------|
| 국내 AMR/AGV | 3.5조원 (2025) | 5조원 (2027), 12.4조원 (2031) |
| 글로벌 로봇 | 741억$ (2026) | 연 7% 성장 |
| 협동로봇 | 50.8억$ (2025) | 연 43.5% 성장 |

### 2.2 기술적 배경

#### 메카넘휠 기술의 장점
```
일반 바퀴 vs 메카넘휠

[일반 바퀴]
├── 전진/후진만 가능
├── 회전 시 공간 필요
└── 평지 전용

[메카넘휠]
├── 360도 전방향 이동
├── 제자리 회전 (회전반경 0m)
├── 측면 이동 가능
└── 정밀 위치 제어 (±1mm)
```

#### 기존 기술의 한계
| 구분 | 기존 기술 | 한계점 |
|------|----------|--------|
| 해외 제품 | 고가 (수천만원) | 국내 중소기업 도입 어려움 |
| 국내 제품 | 아날로그 제어 | 정밀도/안정성 부족 |
| 범용 AMR | 전방향 이동 불가 | 협소공간 운용 제한 |

### 4.2 세부 개발 내용

#### 1단계: 제어 시스템 고도화 (1~4개월)

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| ESP32-S3 USB 통신 | Native USB 기반 NDJSON 프로토콜 | 펌웨어 v1.0 |
| 모터 제어 알고리즘 | PID 제어 + FOC 구현 | 제어 라이브러리 |
| 메카넘 역기구학 | 4륜 독립 속도 계산 | 수학 모델 검증 |

**메카넘휠 역기구학 공식:**
```
FL = linear_x + linear_y + angular_z
FR = linear_x - linear_y - angular_z
RL = linear_x - linear_y + angular_z
RR = linear_x + linear_y - angular_z

(FL: 전방좌, FR: 전방우, RL: 후방좌, RR: 후방우)
```

#### 2단계: AI 통합 (5~8개월)

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| AI 가속기 통합 | Raspberry Pi 5 + Hailo-8 (26 TOPS) | 하드웨어 통합 |
| 객체 인식 모델 | 사람/장애물 실시간 인식 | 학습 모델 |
| 추종/회피 알고리즘 | 사람 추종, 충돌 회피 로직 | SW 모듈 |

#### 3단계: 검증 및 실증 (9~12개월)

| 개발 항목 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 실내 테스트 | 정밀도, 속도, 안정성 검증 | 테스트 보고서 |
| 현장 실증 | 교육기관/물류창고 PoC | 실증 결과서 |
| 문서화 | 사용자 매뉴얼, API 문서 | 기술 문서 |
