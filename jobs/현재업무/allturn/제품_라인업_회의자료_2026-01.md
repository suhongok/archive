## 2. ATOM - 교육용 메카넘휠 로봇

### 2.1 제품 사양
| 항목 | 사양 |
|------|------|
| 적재용량 | 60kg 이하 |
| 주행방식 | 360도 전방향 (메카넘휠) |
| 메인 컨트롤러 | **라즈베리파이5** |
| 모터 제어 | **ESP32-S3** (USB JSON 통신) |
| 제어방식 | **PS4 컨트롤러 + 스마트폰 앱** |
| AI 기능 (옵션) | 사람 추종, 장애물 회피 |
| 예상가격 | 500~1,000만원 |

### 2.2 제어 시스템 구조
```
┌─────────────────────────────────────────────────────────┐
│                      사용자 입력                         │
├─────────────────┬───────────────────────────────────────┤
│  PS4 컨트롤러   │           스마트폰 앱                  │
│  (Bluetooth)    │    (WiFi / Bluetooth)                 │
└────────┬────────┴──────────────┬────────────────────────┘
         │                       │
         ▼                       ▼
┌─────────────────────────────────────────────────────────┐
│              라즈베리파이5 (메인 컨트롤러)               │
│  - 입력 처리 및 명령 변환                               │
│  - AI 추론 (Hailo-8 연동 시)                            │
│  - 웹 서버 / 앱 통신                                    │
└────────────────────────┬────────────────────────────────┘
                         │ USB (JSON)
                         ▼
┌─────────────────────────────────────────────────────────┐
│              ESP32-S3 (모터 제어 MCU)                    │
│  - Allturn USB NDJSON Protocol v1                       │
│  - cmd_vel → 메카넘휠 변환                              │
│  - 모터 PWM 제어 (50Hz)                                 │
└─────────────────────────────────────────────────────────┘
```

### 2.3 개발 현황
- **ESP32-S3 USB JSON 통신**: 구현 완료
- **PS4 컨트롤러 연동**: 라즈베리파이5에서 처리
- **스마트폰 앱**: 개발 예정 (WiFi 기반 웹앱 또는 네이티브 앱)

## 3. ODIN - 메카넘휠 지게차/고소작업차/중량물 운반차량

### 3.1 제품 사양
| 항목 | 사양 |
|------|------|
| 주행반경 | 제자리 회전 (0m) |
| 정렬오차 | ±10mm |
| 공간효율 | 기존 대비 +40% |
| 안전기능 | E-Stop, 충돌회피, 사람인식 경보 |
| AI 플랫폼 | Jetson Orin Nano / 라즈베리파이5 + Hailo-8 |
| 예상가격 | 3,000~5,000만원 |

### 3.2 현재 개발 이슈 및 해결 방안

#### 문제점: 라이다(LiDAR) 매핑 한계
- 실외 환경에서 반사/투과 문제
- 유리, 반짝이는 표면 인식 어려움
- 동적 객체 추적 정확도 부족

#### 해결 방안: Depth 카메라 적용
```
┌─────────────────────────────────────────────────────────┐
│                   센서 퓨전 전략                         │
├─────────────────────────────────────────────────────────┤
│  기존: LiDAR 단독                                       │
│        ↓                                                │
│  변경: LiDAR + Depth 카메라 (센서 퓨전)                 │
│        - Intel RealSense D435i / D455                   │
│        - Orbbec Femto Bolt                              │
│        - Stereolabs ZED 2i                              │
└─────────────────────────────────────────────────────────┘
```

| Depth 카메라 후보 | 특징 | 가격대 |
|------------------|------|--------|
| Intel RealSense D435i | 스테레오 + IMU, ROS2 지원 | ~50만원 |
| Intel RealSense D455 | 장거리, 고정밀 | ~70만원 |
| Orbbec Femto Bolt | ToF 방식, Azure Kinect 호환 | ~80만원 |
| ZED 2i | 4K, AI 내장, 방수 | ~100만원 |

### 3.3 개발 단계
```
Phase 1 (완료)     Phase 2 (현재)      Phase 3 (계획)
원격제어 +    →    자율 내비게이션  →   자율 적재
AI 안전기능        LiDAR + Depth       VLM 물체 인식
                   카메라 매핑         그리퍼 제어
```

### 3.4 현재 진행 상황
- **프로토타입**: 보유 (즉시 시연 가능)
- **LiDAR 매핑**: 기본 구현 완료, 한계 도출
- **Depth 카메라**: 선정 및 통합 테스트 예정
- **ROS2 내비게이션**: 구현 중

#### Physical AI 개념 적용
```
┌─────────────────────────────────────────────────────────┐
│                   Physical AI 개념                       │
├─────────────────────────────────────────────────────────┤
│  기존 AI: 인식 → 판단 → 명령                            │
│           (소프트웨어 중심)                              │
│                                                         │
│  Physical AI: 인식 → 판단 → 물리적 상호작용             │
│               (하드웨어 + 소프트웨어 통합)               │
│                                                         │
│  적용 분야:                                             │
│  ├── 지형 적응: 실시간 지면 분석 → 휠 토크 조절         │

│  ├── 환경 상호작용: 힘 피드백 → 동작 최적화            │
│  └── 인간 협업: 의도 예측 → 안전한 공동 작업            │
```
