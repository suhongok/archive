# 한국건설기계연구원 미팅 브레인스토밍

**일시**: 2026년 1월 (다음주)
**장소**: 전북 한국건설기계연구원
**목적**: 험지전용 메카넘휠 + 피지컬 AI 연구과제 선정

---

## 연구과제 후보

### 1. 건설현장 자율 자재운반 로봇
| 항목 | 내용 |
|------|------|
| **개요** | 험지 지형(흙, 자갈, 경사면)에서 자재를 자율 운반 |
| **피지컬 AI** | 지형 인식 → 바퀴 슬립 예측 → 실시간 토크 보정 |
| **메카넘 강점** | 좁은 현장에서 측면 이동, 제자리 회전으로 정밀 배치 |
| **활용** | 벽돌, 철근, 소형 자재 운반 |

---

### 2. 터널/지하공간 자율 점검 로봇
| 항목 | 내용 |
|------|------|
| **개요** | 터널 공사 중/완공 후 균열, 누수, 가스 자동 점검 |
| **피지컬 AI** | 벽면 균열 감지 + 위치 매핑 + 위험도 자동 분류 |
| **메카넘 강점** | 울퉁불퉁한 터널 바닥, 좁은 공간 전방향 이동 |
| **활용** | 터널, 지하주차장, 하수관로 점검 |

---

### 3. 험지형 스마트 고소작업 플랫폼
| 항목 | 내용 |
|------|------|
| **개요** | 불균일 지면에서 자세 자동 보정하는 고소작업대 |
| **피지컬 AI** | IMU + 카메라 지형 분석 → 리프트 각도 자동 조정 → 전복 방지 |
| **메카넘 강점** | 작업 중 미세 위치 조정, 장애물 회피 |
| **활용** | 교량 하부 점검, 건물 외벽 작업, 스마트팜 |
| **비고** | 올턴 기존 프로젝트와 직결 |

---

### 4. 건설현장 안전 순찰 로봇
| 항목 | 내용 |
|------|------|
| **개요** | 현장 자율 순찰하며 안전 위험요소 감지 및 경보 |
| **피지컬 AI** | 작업자 PPE 착용 확인, 위험구역 침입 감지, 장비 충돌 예측 |
| **메카넘 강점** | 험지 주행 + 좁은 통로 + 중장비 사이 기동 |
| **활용** | 대형 건설현장 24시간 안전 모니터링 |

---

### 5. 재난현장 탐색/정찰 로봇
| 항목 | 내용 |
|------|------|
| **개요** | 붕괴 건물, 산사태 현장에서 생존자 탐색 |
| **피지컬 AI** | 열화상 + 음성 감지 + 잔해물 사이 경로 계획 |
| **메카넘 강점** | 잔해물 위 험지 주행, 협소 공간 진입 |
| **활용** | 소방청/재난안전 연계 가능 |

---

### 6. 중장비 협업 자율 보조 로봇
| 항목 | 내용 |
|------|------|
| **개요** | 굴삭기/크레인 주변 자재 준비, 신호수 역할 대체 |
| **피지컬 AI** | 중장비 동선 예측 → 안전거리 유지 → 작업자 위치 추적 |
| **메카넘 강점** | 중장비 주변에서 민첩한 회피 기동 |
| **활용** | 스마트 건설현장 자동화 |

### 올턴 강점
- 험지 메카넘휠 설계/제조 경험
- Hailo-8 AI 가속기 통합 경험
- ESP32-S3 기반 제어 시스템 구축

### 피지컬 AI 차별점
- 단순 자율주행 X
- **지형 적응형 제어** (슬립 보정, 자세 안정화)

- 건설기계연구원: 험지 테스트베드, 건설기계 전문성
- 올턴: 메카넘 플랫폼, AI 엣지 컴퓨팅
