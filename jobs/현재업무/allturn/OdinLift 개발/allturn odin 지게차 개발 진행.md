# 1. 하드웨어 아키텍처

## 1.1 분산 제어 시스템 구조

### 전체 시스템 아키텍처

```
[Raspberry Pi 5] (ROS2 상위 제어)
        |
    [CAN Bus]
        |
        +--- [ESP32-S3 #1] (메카넘휠 제어 , 유압제어)
        |         |
        |         +--- 485 서보 드라이버(엔코더내장) x4
        |         +--- IMU 센서
	      |         +--- 릴레이 모듈 (4채널) - 유압모터 on/off, 서보드라이버 전원 on/off
        |
        +--- [ESP32-P4 #2] (통합 제어 & 인터페이스)
        |         |
        |         +--- 산업용 리모컨 수신(메인 제어)
        |         +--- 블루투스 리모컨
        |         +--- 터치 모니터(설정 변경, 상태 표시)
        |
        +--- [ESP32 #3] (센서 제어)
        |         |
                  +--- 초음파 센서 x7
                  +--- 장애물 감지 로직
```

### 각 ESP32 모듈 역할

**ESP32-S3 #1 (메카넘휠 제어기)**

- 4개 모터 드라이버 제어 (485 통신)
- 메카넘휠 역기구학 계산
- 엔코더 피드백 처리
- IMU 데이터 통합
- ROS2통신
- 로컬 PID 제어
- 릴레이 모듈 구동 (4채널)

**ESP32-P4 #2 (원격제어 & 통합 인터페이스)**

- 무선 조종기 신호 수신 (산업용/블루투스)
- ROS2 명령 수신 및 변환
- CAN Bus 마스터 역할
- 메인 HMI 터치패널 제어
- 통합 제어 명령 생성 및 배포
- 전체 시스템 상태 모니터링

**ESP32S3 #3 (센서 제어기)**

- 다중 초음파 센서 관리 (7개)
- 실시간 장애물 감지
- 센서 데이터 필터링 및 융합
- 안전 정지 신호 생성
- 근접 경고 알고리즘
- 배터리 제어

## 1.2 통신 시스템

### CAN Bus 기반 통신 (권장)

**CAN Bus를 선택한 이유:**

- 산업용 표준 (자동차/공장 검증됨)
- 높은 신뢰성 및 실시간성
- 강한 노이즈 내성 (전동 공구, 용접기 등)
- 하드웨어 에러 검출 (CRC, ACK 등)
- 우선순위 중재 메커니즘
- 저렴한 구현 비용 (트랜시버 ~$2)

**하드웨어 구성:**

```
각 ESP32 + SN65HVD230 CAN 트랜시버
           |
       CAN_H/CAN_L (Twisted Pair)
           |
      120Ω 종단저항 (양 끝)
```

**CAN ID 할당 체계:**

```
0x001  비상정지 (최우선)
0x010  안전 센서 데이터
0x100  모터 제어 명령
0x101  모터 피드백
0x200  릴레이 제어명령(서보드라이버 on/off, 유압펌프제어)
0x300  초음파 센서 데이터
0x400  시스템 설정
0x700  디버그 정보 (낮은 우선순위)
```

**통신 속도:**

- CAN Bus: 500 kbps (신뢰성/속도 균형)
- 최대 케이블 길이: 40m (지게차 내부 충분)

### Raspberry Pi 5 연결

- CAN to USB 어댑터 또는
- Raspberry Pi HAT (CAN 인터페이스)
- ROS2 SocketCAN 드라이버 사용

## 1.4 유압 시스템 제어 (신규 추가)

### 릴레이 기반 포크 제어

**하드웨어 구성:**

```
[ESP32 #1] 
    |
    +--- 485채널 → [4채널 릴레이 모듈]
                      |
                      +--- 릴레이 1: 서보드라이버 on/off
                      +--- 릴레이 2: (유압펌프모터)포크 UP
                      +--- 릴레이 3: (유압펌프모터)포크 DOWN
                      +--- 릴레이 4: (유압펌프모터)틸트 전방
                      +--- 릴레이 5: (유압펌프모터)틸트 후방

```

**릴레이 모듈 사양:**

- 정격: 10A 이상 (유압펌프 전류 고려)
- 타입: 릴레이 모듈 485통신
- 보호: 역기전력 방지 다이오드 필수
- 채널: 6채널

**제어 로직:**

```cpp
// 동시 작동 방지 인터록
if (relay_up && relay_down) {
    emergency_stop();
    log_error("Interlock violation");
}

// 리미트 스위치 체크
if (upper_limit_switch) {
    disable_relay_up();
}
if (lower_limit_switch) {
    disable_relay_down();
}

// 타임아웃 안전
if (relay_on_time > MAX_ON_TIME) {
    disable_all_relays();
    log_warning("Timeout protection");
}
```

**안전 기능:**

- 상/하한 리미트 스위치 연동
- 동시 작동 방지 (UP+DOWN 동시 불가)
- 과부하 감지 (전류 센서)
- Watchdog 타이머
- 비상정지 시 모든 릴레이 OFF
- 릴레이 상태 피드백
- 최대 작동 시간 제한

**유압 파라미터:**

- 포크 상승 속도: 0.1 m/s
- 최대 높이: 1.5m
- 틸트 각도: ±10도
- 틸트 속도: 5 deg/s
- 최대 하중: 500kg

# 3. 기능별 구현 계획

## 3.1 메카넘휠 주행 제어

**구현 우선순위**: P0 (최우선)

### 요구사항

- 전후좌우 이동 및 제자리 회전
- 대각선 이동
- 부드러운 가감속 프로파일
- 최대 속도 제한: 1.5 m/s (안전 고려)
- 최대 가속도 제한: 0.5 m/s²

### 구현 방법

```cpp
// 역기구학 기반 메카넘휠 제어
// 입력: vx, vy, omega (전후, 좌우, 회전 속도)
// 출력: 각 바퀴 속도 (wheel_FL, FR, RL, RR)

wheel_FL = vx - vy - omega * (Lx + Ly)
wheel_FR = vx + vy + omega * (Lx + Ly)
wheel_RL = vx + vy - omega * (Lx + Ly)
wheel_RR = vx - vy + omega * (Lx + Ly)
```

### 테스트 시나리오

1. 직선 주행 (전후좌우)
2. 대각선 주행 (45도 방향)
3. 제자리 회전
4. 복합 동작 (전진하며 회전)
5. 급정지 테스트

## 3.2 지게차 동작 제어

**구현 우선순위**: P0

### 기능

- **포크 업다운**: 최대 높이 1.5m, 속도 0.1 m/s
- **포크 틸트**: ±10도, 속도 5 deg/s
- **안전 인터록**: 주행 중 포크 동작 제한

### 안전 규칙

- 포크 최대 높이에서 주행 속도 50% 제한
- 포크 내릴 때 하중 감지
- 과부하 감지 시 동작 중지

## 3.3 사람 인식 정지 (K230 카메라)

**구현 우선순위**: P1

### Phase 1: 기본 안전 기능

- 전방 3m 이내 사람 감지 시 경보
- 전방 1.5m 이내 사람 감지 시 자동 정지
- 측면 접근 감지 (좌우 1m)

### Phase 2: 동적 안전영역

- 속도에 따른 안전거리 조절
    - 1.5 m/s: 3.0m 안전거리
    - 1.0 m/s: 2.0m 안전거리
    - 0.5 m/s: 1.5m 안전거리
- 사람 이동 방향 예측
- 단계적 감속 (경고 → 감속 → 정지)

### AI 모델

- YOLO 기반 사람 감지 (K230 온보드 처리)
- 실시간 추론 속도: 30 FPS 이상
- 신뢰도 임계값: 0.7 이상

## 3.4 LED 상태 표시

**구현 우선순위**: P2

### 상태 정의

- **녹색 점등**: 정상 대기
- **녹색 점멸**: 정상 주행
- **노란색 점등**: 경고 (사람 근접)
- **노란색 점멸**: 저배터리
- **빨간색 점등**: 오류 발생
- **빨간색 점멸**: 비상정지
- **파란색**: 원격 제어 모드

## 3.5 초음파 센서 충돌 감지

**구현 우선순위**: P1

### 센서 배치

- 전방: 3개 (좌, 중앙, 우)
- 후방: 2개 (좌, 우)
- 측면: 2개 (좌, 우)

### 동작 로직

- 30cm 이내 장애물 감지 시 즉시 정지
- 50cm 이내 감지 시 속도 50% 감속
- 센서 융합: 카메라 + 초음파 통합 판단

## 3.6 리모컨 제어

**구현 우선순위**: P0

### 산업용 리모컨 (주 제어기)

- 2.4GHz 무선 통신
- 조이스틱: 주행 제어
- 버튼: 포크 업다운, 틸트
- 비상정지 버튼
- 작동 거리: 최대 100m

### 블루투스 리모컨 (보조)

- 스마트폰 앱 연동
- 제한된 속도 (안전을 위해 50% 제한)
- 카메라 영상 스트리밍

### 카메라 기반 원격제어

- ESP32-S3 Cam 별도 모듈
- FPV 영상 전송 (저지연)
- 웹 인터페이스 제공

# 4. 개발 로드맵 (마일스톤 기반)

## M0: 시제품 → 상품화 준비 (현재 ~ 1개월)

**목표**: 안전 기준 정립 및 기본 기능 안정화

### 주요 작업

1. **안전 요구사항 문서화**
    - 최고속도: 1.5 m/s
    - 정지거리: 속도의 제곱에 비례 (1.5 m/s에서 0.5m)
    - 회전반경: 제자리 회전 가능
    - 허용 경사: 최대 5도

2. **고장 모드 정의 (FMEA)**
    - 통신 끊김 → 3초 이내 안전정지
    - 센서 이상 → 경고 출력 및 속도 제한
    - 바퀴 슬립 → IMU 기반 감지 및 정지
    - 과전류 → 모터 차단 및 경고
3. **기본 제어 코드 완성**
    - ESP32-S3 메카넘휠 제어
    - 485 통신 안정화
    - 리모컨 입력 처리

### 산출물

- 안전 요구사항 문서 (Safety Requirements Specification)
- FMEA 문서
- 기본 제어 펌웨어 v0.1

# 5. 안전 요구사항 상세

## 5.1 기계적 안전

### 정지거리 요구사항

- 최대 속도 1.5 m/s에서 정지거리 0.5m 이하
- 비상정지 시 0.3m 이하

### 안정성

- 최대 허용 경사: 5도
- 전복 방지: 무게 중심 낮게 설계
- 충격 흡수: 범퍼 장착

## 5.2 전기적 안전

### 전원 관리

- 과전류 보호 회로
- 배터리 저전압 경고
- 충전 중 운행 금지

### 비상정지

- E-Stop 버튼 (2개 이상)
- 무선 비상정지 (리모컨)
- 자동 비상정지 (센서 기반)

## 5.3 기능 안전 (Functional Safety)

### 통신 안전

- Watchdog: 3초 이내 통신 없으면 정지
- 리모컨 신호 끊김 감지
- 체크섬 검증

### 센서 이상 처리

- 센서 고장 감지
- 백업 센서로 전환
- 안전 모드로 운행 (저속)

### 소프트웨어 안전

- Fail-safe 설계
- 이중화 (센서, 통신)
- 로그 기록 (블랙박스)

## 5.4 작업 안전

### 작업자 보호

- 사람 감지 시 자동 정지
- 경고음 및 경광등
- 안전 영역 표시 (LED)

### 화물 안전

- 과부하 감지
- 틸트 각도 제한
- 주행 중 포크 높이 제한
