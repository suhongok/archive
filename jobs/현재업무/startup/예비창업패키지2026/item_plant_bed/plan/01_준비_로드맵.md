## Phase 1: 사전 준비 (1월 ~ 2월 초)

### 1주차: 아이템 구체화
- [ ] 창업 아이템 아이디어 정리
- [ ] 해결하고자 하는 문제 정의
- [ ] 타겟 고객 설정
- [ ] 기존 솔루션/경쟁사 1차 조사

### 2주차: 시장 조사
- [ ] 시장 규모 조사 (TAM/SAM/SOM)
- [ ] 경쟁사 심층 분석
- [ ] 고객 니즈 검증 (인터뷰/설문)
- [ ] 트렌드 및 성장성 분석

### 3주차: 비즈니스 모델 설계
- [ ] 수익 모델 설계
- [ ] 가격 전략 수립
- [ ] 고객 획득 채널 정의
- [ ] 핵심 가치 제안 정리

### 4주차: 사업계획서 초안
- [ ] 사업계획서 뼈대 작성
- [ ] 문제-솔루션 스토리 구성
- [ ] 차별화 포인트 정리
- [ ] 팀 소개 자료 준비

## Phase 2: 신청 준비 (2월)

### 공고 발표 후 즉시
- [ ] 2026년 공고문 상세 확인
- [ ] 지원 자격 요건 재확인
- [ ] 변경 사항 파악
- [ ] 주관기관 리스트 확인

### 주관기관 선택
- [ ] 주관기관별 특징 조사
- [ ] 아이템과의 적합성 판단
- [ ] 경쟁률 참고 (단, 맹신 금물)
- [ ] 최종 주관기관 결정

### 사업계획서 완성
- [ ] 공고문 양식에 맞춰 수정
- [ ] 구체적 수치/데이터 보강
- [ ] 사업비 사용 계획 작성
- [ ] 마일스톤 확정

### 서류 준비
- [ ] 필수 제출 서류 확인
- [ ] 증빙 서류 준비
- [ ] 온라인 제출 테스트

## Phase 3: 서류 접수 (3월)

### 접수 전
- [ ] 사업계획서 최종 검토
- [ ] 오탈자/수치 오류 확인
- [ ] 타인 피드백 반영
- [ ] 제출 서류 체크리스트 확인

### 접수
- [ ] K-Startup 회원가입/로그인
- [ ] 온라인 신청서 작성
- [ ] 파일 업로드
- [ ] 최종 제출 및 확인증 저장

## Phase 4: 평가 준비 (4월)

### 인큐베이팅 기간
- [ ] 주관기관 프로그램 참여
- [ ] 사업계획 보완
- [ ] 멘토링 적극 활용
- [ ] 발표 자료 준비

### 발표 평가 준비
- [ ] PT 자료 제작 (10분 내외)
- [ ] 예상 질문 리스트 작성
- [ ] 모의 발표 연습 (최소 5회)
- [ ] 복장/태도 점검

## Phase 5: 선정 후 (5월~)

### 협약 체결
- [ ] 선정 결과 확인
- [ ] 협약 서류 준비
- [ ] 사업자등록 진행
- [ ] 협약 체결

### 사업 수행
- [ ] 사업비 관리 체계 구축
- [ ] 마일스톤별 실행
- [ ] 정기 보고 준비
- [ ] 중간평가 대비

## 핵심 체크포인트

### 절대 놓치지 말아야 할 것
1. **공고 발표일 확인** (2월 예상)
2. **신청 마감일** (마감 직전 제출 금물)
3. **사업자등록 여부** (접수일 기준 없어야 함)
4. **주관기관 선택** (아이템 적합성 우선)

### 미리 준비하면 좋은 것
1. 사업계획서 70% 이상 완성
2. 시장 조사 데이터 확보
3. 팀 구성 (해당 시)
4. 시제품/MVP 기획
