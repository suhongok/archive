# item 폴더 안내

## 이 폴더의 용도
창업 아이템을 구체화하고 정리하는 공간입니다.

## 포함된 파일
- `아이템_기획서_템플릿.md` - 아이템 기획서 작성용 템플릿

## 사용 방법

### 1. 템플릿 복사
`아이템_기획서_템플릿.md` 파일을 복사하여 새 파일을 만드세요.

예시:
- `내_아이템_기획서.md`
- `아이템A_기획서.md`

### 2. 내용 채우기
템플릿의 각 섹션을 본인의 아이템에 맞게 채워주세요.

### 3. 지속적 업데이트
시장 조사, 고객 인터뷰 등을 통해 지속적으로 보완하세요.

## 추가로 넣으면 좋은 파일들

```
item/
├── 아이템_기획서_템플릿.md  (제공됨)
├── 내_아이템_기획서.md      (직접 작성)
├── 시장조사_자료/           (시장 조사 데이터)
├── 경쟁사_분석/            (경쟁사 분석 자료)
├── 고객_인터뷰/            (인터뷰 결과)
└── 아이디어_스케치/         (서비스 화면 기획 등)
```

## 작성 순서 권장

1. **문제 정의** - 가장 먼저 명확히
2. **솔루션** - 문제 해결 방법
3. **시장 분석** - 객관적 데이터 수집
4. **비즈니스 모델** - 수익 창출 방안
5. **경쟁 분석** - 차별화 포인트
6. **나머지 섹션** - 순차적 완성
