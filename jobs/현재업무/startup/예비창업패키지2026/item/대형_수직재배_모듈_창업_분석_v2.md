# 대형 수직재배 모듈(식물베드) 창업 아이템 심층 분석 v2

> **제품 스펙**: 2m × 0.7m × 2m / 포트 8개 / 컨테이너팜·실내농장용

## Executive Summary

**결론: 적극 추천 ⭐⭐⭐⭐☆ (4/5)**

가정용 소형 재배기와 **완전히 다른 시장**입니다. 컨테이너팜/실내농장 운영자 대상 **B2B 장비 시장**은 대기업(LG, 교원)이 진출하지 않은 영역이며, **정부 지원(55% 보조금)**과 맞물려 성장 가능성이 높습니다.

**핵심 강점**: 스마트팜 동호회에서 **5명 관심 표명** = 초기 고객 검증 시작

## 4. SWOT 분석 (수정)

### Strengths (강점)

1. **기술 경쟁력**
   - 양액 pH/EC 자동 제어 (경쟁사 대비 우위)
   - CO₂ 농도 관리 (생산성 향상)
   - MQTT 원격 모니터링

2. **가격 경쟁력**
   - BOM 약 33만원 (소형 기준, 대형은 스케일업)
   - 대형 시스템 대비 저렴한 모듈 단가
   - 정부 보조금(55%) 적용 시 부담 감소

3. **모듈형 설계**
   - 1대부터 구매 가능
   - 필요시 추가 확장
   - 컨테이너 내 자유로운 배치

4. **초기 고객 확보 가능성**
   - 스마트팜 동호회 5명 관심
   - 커뮤니티 기반 마케팅 가능

### Weaknesses (약점)

1. **브랜드 인지도 없음**
   - 신생 업체 신뢰 문제
   - 레퍼런스 부족

2. **양산 경험 부족**
   - 대형 모듈 제작 경험 필요
   - 품질 일관성 확보 과제

3. **A/S 체계 미구축**
   - 전국 서비스망 부재
   - 원격 A/S로 일부 보완 가능

### Opportunities (기회)

1. **정부 지원 정책**
   - 컨테이너팜 도입 시 **55% 보조금**
   - 25% 저리 융자
   - 수직농장 연계 지원사업 7개

2. **시장 성장**
   - 컨테이너팜 연 12% 성장
   - 귀농귀촌 인구 증가
   - 도시농업 확대

3. **중간 가격대 공백**
   - 대기업 솔루션 (수억) ↔ DIY (불안정)
   - 그 사이 시장 기회

4. **해외 수출 가능성**
   - 중동, 동남아 수요
   - 컨테이너 운송 용이

### Threats (위협)

1. **대기업 진출 가능성**
   - 시장 성장 시 대기업 관심

2. **기술 모방**
   - 진입장벽 낮으면 카피 발생

3. **전력비 이슈**
   - 수직농장 전기료 부담
   - 고객 수익성 영향
