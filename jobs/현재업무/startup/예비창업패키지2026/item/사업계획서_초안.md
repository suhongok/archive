# 2. 문제 정의

## 2.1 해결하고자 하는 문제

### 문제 1: 컨테이너팜 운영의 어려움

```
"컨테이너팜을 시작했는데, 양액 관리가 너무 어려워요"
"매일 pH, EC 측정하고 조절하는 데만 2시간이 걸려요"
"출장 가면 농장이 걱정돼서 마음 편히 못 쉬어요"
```

**현실:**
- 컨테이너팜/실내농장 창업자 증가 (귀농귀촌, 도시농업)
- 하지만 **양액 관리는 여전히 수동**
- 전문 지식 없으면 실패 확률 높음
- 24시간 관리 필요 → 삶의 질 저하

### 문제 2: 기존 솔루션의 한계

| 기존 솔루션 | 문제점 |
|------------|--------|
| 대기업 시스템 (엔씽 등) | **너무 비쌈** (수억원대) |
| 컨테이너팜 전체 구축 | **초기 비용 부담** (4,500만원+) |
| 저가 중국산 모듈 | **품질 불안정**, A/S 불가 |
| DIY 자작 | **전문 지식 필요**, 시간 소모 |

### 문제 3: 통계로 보는 문제의 크기

- 컨테이너팜 도입 유보 이유 1위: **초기 투자 비용 부담 (32%)**
- 운영비 부담: 24%
- 기술 습득 어려움: 10%
- 국내 수직농장 보급률: **5% 미만** (성장 잠재력 큼)

## 2.2 왜 지금인가?

1. **정부 정책 지원**
   - 스마트농업 육성 기본계획 (2025~2029)
   - 컨테이너팜 도입 시 **55% 보조금 + 25% 융자**
   - 실질 고객 부담 20%로 감소

2. **시장 성장**
   - 국내 실내농업 시장: 연 **75% 성장**
   - 글로벌 컨테이너 스마트팜: 연 12% 성장 → 2027년 87억$

3. **사회적 필요**
   - 기후변화로 노지 농업 불확실성 증가
   - 식량 안보 이슈 부각
   - 도시 근교 신선 농산물 수요

# 3. 솔루션

## 3.1 제안하는 솔루션

> **"양액 자동제어로 누구나 쉽게 운영하는 모듈형 수직재배 시스템"**

### 핵심 가치

| 기존 방식 | 우리 솔루션 |
|-----------|-------------|
| 매일 2시간 양액 관리 | **완전 자동화**, 손 안 대도 됨 |
| 전문가만 가능 | **초보자도 가능** |
| 수억원 초기 비용 | **1대부터 구매** (수백만원) |
| 현장 상주 필수 | **원격 모니터링** |

### 작동 원리

```
[양액 자동제어 시스템 흐름]

센서 측정 (5분 주기)
    │
    ├─→ pH 센서: 현재 6.8 (목표 5.8)
    │       └─→ "pH 높음" 판단
    │           └─→ pH Down 펌프 자동 작동 (1ml)
    │               └─→ 교반 → 3분 대기 → 재측정
    │
    ├─→ EC 센서: 현재 1.0 (목표 1.4)
    │       └─→ "EC 낮음" 판단
    │           └─→ 양액 A/B 펌프 자동 작동
    │
    └─→ 모든 데이터 → MQTT → 스마트폰 앱
                              └─→ 이상 시 푸시 알림
```

## 3.2 제품 라인업

| 모델 | 기능 | 예상 가격 | 정부보조 후 |
|------|------|----------|------------|
| **Basic** | 환경제어 (온습도/LED) | 250만원 | **112만원** |
| **Standard** | + 양액 자동화 (pH/EC) | 450만원 | **202만원** |
| **Pro** | + CO₂ + 원격모니터링 + 데이터분석 | 650만원 | **292만원** |

*정부 보조금 55% 적용 기준
