## 1. 청년창업사관학교

### 1.1 사업 개요

청년창업사관학교(청창사)는 **중소벤처기업진흥공단(중진공)**이 운영하는 대한민국 대표 청년 창업가 육성 프로그램입니다. 창업 초기(3년 이내) 청년에게 **사업화 자금 + 사무공간 + 멘토링 + 교육 + 전문가 코칭**을 원스톱으로 제공합니다.

| 항목 | 내용 |
|------|------|
| 주관 기관 | 중소벤처기업진흥공단 |
| 사업 유형 | 창업성공패키지 지원사업 |
| 지원 형태 | 보조금 (상환 불필요) |
| 캠퍼스 | 전국 18개 |

---

### 1.2 지원 자격

#### 기본 자격 요건

| 구분 | 조건 |
|------|------|
| **연령** | 만 39세 이하 |
| **창업 기간** | 창업 3년 이내 초기 창업자 |
| **아이템** | 유망한 아이템 및 혁신 기술 보유자 |

#### 지원 유형별 자격

| 유형 | 대상 |
|------|------|
| **입교형** | 창업 1~3년차 |
| **준입교형** | 예비창업자 ~ 창업 1년차 |

#### 지원 제외 대상

- 단순 도소매, 음식점, 프랜차이즈 가맹점 등 기술창업이 아닌 업종
- 국세·지방세 체납자
- 동일·유사 아이템으로 정부지원 중복 수혜자
- 휴·폐업 중인 자

---

### 1.3 지원 내용

#### 1.3.1 사업화 자금

| 항목 | 내용 |
|------|------|
| **지원 금액** | 최대 1억 원 (총사업비의 70% 이내) |
| **자부담** | 총사업비의 30% |
| **지급 방식** | 단계별 차등 지급 |

#### 1.3.2 사업비 사용 가능 항목

| 구분 | 항목 |
|------|------|
| **사용 가능** | 개발비, 시제품 제작, 지재권 출원, 마케팅, 인건비 일부, 외주개발비 |
| **사용 불가** | 대표자 급여, 토지·임대료, 금융수수료, 접대비 등 |

#### 1.3.3 종합 지원 체계

| 지원 분야 | 세부 내용 |
|-----------|----------|
| **정부지원금** | 기술개발 및 시제품 제작, 마케팅 비용 등 |
| **창업 인프라** | 창업 준비 공간, 제품개발 장비 제공 |
| **창업 교육** | 창업 단계별 집중 교육 프로그램 |
| **창업 코칭** | 전담교수 1:1 집중 코칭 |
| **기술 지원** | 제품개발 과정의 기술 및 장비 지원 |
| **투자 지원** | 투자전담운영사 활용, 데모데이 실시 |
| **정책사업 연계** | 정책자금, 수출지원, 기술개발, 투자유치 연계 |

---

### 1.4 선발 절차

#### 전체 프로세스

```
사업 공고 → 온라인 신청 → 서류 평가 → 발표 평가(PT) → 최종 선정 → 입교
```

#### 단계별 상세

| 단계 | 내용 | 비고 |
|------|------|------|
| **1단계: 공고** | K-Startup 홈페이지 공고 확인 | 1월 중 |
| **2단계: 신청** | K-Startup 온라인 접수 | 약 3주간 |
| **3단계: 서류평가** | 사업계획서 기반 평가 | - |
| **4단계: 발표평가** | PT 발표 심사 | 창업자 역량 중점 평가 |
| **5단계: 최종선정** | 입교생 확정 | 2~3월 |

#### 평가 기준

- 창업자 역량 (이력, 전문성, 창업 경험)
- 사업 아이템의 혁신성 및 기술성
- 시장성 및 성장 가능성
- 사업계획의 구체성

#### 가점 요소

- 수상 경력
- 특허 보유
- 투자 유치 실적
- 패스트트랙 적용 가능

---

| 일정 | 내용 |
|------|------|
| 2025년 12월 19일 | 정부 창업지원사업 통합 공고 |
| 2026년 1월 20일 ~ 23일 | 청창사 개별 모집 공고 (예상) |
| 2026년 1월 23일 ~ 2월 12일 | 접수 기간 (약 3주간, 16:00 마감 예상) |
| 2026년 2월 ~ 3월 | 평가 및 발표 |
| 2026년 3월 ~ | 프로그램 진행 |

---

### 1.6 선정 규모 (2026년)

| 유형 | 선발 인원 |
|------|----------|
| 글로벌형 | 330명 |
| 지역특화형 | 310명 |
| 투자형 | 140명 |
| **총계** | **850명** |

---

### 1.7 신청 방법

1. **K-Startup 홈페이지** 접속 (https://www.k-startup.go.kr)
2. 회원가입 및 로그인
3. 창업성공패키지(청년창업사관학교) 공고 확인
4. 온라인 사업계획서 작성 및 제출
5. 필요 서류 업로드

## 2. 청년전용 창업자금 대출

### 2.1 사업 개요

청년전용 창업자금은 **중소벤처기업진흥공단**에서 운영하는 정책자금 융자사업으로, 청년 창업자에게 시중 금리보다 낮은 금리로 창업 자금을 대출해주는 제도입니다.

| 항목 | 내용 |
|------|------|
| 주관 기관 | 중소벤처기업진흥공단 |
| 자금 유형 | 혁신창업사업화자금 - 창업기반지원자금 |
| 지원 형태 | 융자 (상환 필요) |
| 접수 방식 | 예산 소진 시까지 수시 접수 |

---

### 2.2 지원 자격

#### 기본 자격 요건

| 구분 | 조건 |
|------|------|
| **연령** | 대표자 만 39세 이하 |
| **업력** | 사업 개시일로부터 3년 미만 |
| **대상** | 중소기업 및 창업 준비 중인 예비창업자 |

#### 지원 제외 대상

- 휴·폐업 중인 자
- 국세·지방세 체납자
- 유흥업, 도박업, 부동산 임대업 등 정책자금 지원 제외 업종
- 동일 대표자가 과거 정책자금 부정수급 이력이 있는 경우
- 금융기관 연체 중인 자

---

### 2.3 대출 조건

#### 2.3.1 대출 금리

| 항목 | 내용 |
|------|------|
| **금리** | 연 2.5% (고정금리) |
| **특징** | 시중 금리 대비 저금리 |

#### 2.3.2 대출 한도

| 구분 | 한도 |
|------|------|
| **일반 기업** | 최대 1억 원 |
| **제조업 및 중점지원분야** | 최대 2억 원 |

#### 2.3.3 대출 기간 및 거치 기간

| 자금 유형 | 대출 기간 | 거치 기간 |
|----------|----------|----------|
| **시설자금** | 10년 | 담보: 4년 이내 / 신용: 3년 이내 |
| **운전자금** | 6년 | 3년 이내 |

---

### 2.4 자금 용도

#### 2.4.1 시설자금

| 용도 | 세부 내용 |
|------|----------|
| 기계장비 구입 | 생산, 정보화 촉진, 유통 및 물류, 생산환경 개선 등에 필요한 장비 |
| 토지 구입 | 자가 사업장 확보를 위한 토지 구입비 |
| 건축 자금 | 사업장 건축에 소요되는 비용 |
| 사업장 매입 | 사업장 매입 자금 (경·공매 포함) |

#### 2.4.2 운전자금

| 용도 | 세부 내용 |
|------|----------|
| 원부자재 구입 | 생산에 필요한 원자재 및 부자재 |
| 제품 생산 | 생산 활동에 소요되는 비용 |
| 시장 개척 | 마케팅, 판로 개척 비용 |
| 기술 개발 | R&D 및 기술 개발 비용 |
| 인건비 | 직원 급여 등 |
| 임차보증금 | 사업장 임차보증금 |

---

### 2.5 신청 절차

#### 전체 프로세스

```
온라인 상담예약 → 사전상담 → 정책우선도평가 → 온라인융자신청 → 심사 → 승인 → 대출실행
```

#### 단계별 상세

| 단계 | 내용 | 방법 |
|------|------|------|
| **1단계** | 온라인 상담 예약 | 중진공 홈페이지 |
| **2단계** | 사전 상담 | 담당자 상담 진행 |
| **3단계** | 정책우선도 평가 | 지원 적합성 검토 |
| **4단계** | 온라인 융자 신청 | 필요 서류 제출 |
| **5단계** | 심사 | 서류 및 현장 심사 |
| **6단계** | 승인 및 약정 | 보증기관 연계, 약정 체결 |
| **7단계** | 대출 실행 | 자금 지급 |

---

### 2.6 필요 서류

| 구분 | 서류 |
|------|------|
| **기본 서류** | 사업자등록증, 신분증, 사업계획서 |
| **재무 서류** | 재무제표, 부가가치세 신고서 |
| **담보 서류** | 담보 제공 시 관련 서류 |
| **보증 서류** | 기술보증기금/신용보증기금 보증서 (가점 부여) |

---

### 2.7 가점 요소

- 기술보증기금 보증서 발급
- 신용보증기금 보증서 발급
- 혁신성장 분야 해당 기업
- 지역 균형 발전 기여 기업

---

### 2.8 신청 방법

1. **중소벤처기업진흥공단 홈페이지** 접속 (https://www.kosmes.or.kr)
2. 온라인 상담 예약
3. 사전 상담 진행
4. 융자 신청서 및 서류 제출
5. 심사 결과 대기

## 3. 두 사업 비교

| 비교 항목 | 청년창업사관학교 | 청년전용 창업자금 대출 |
|----------|-----------------|---------------------|

| **청년전용 창업자금 대출** | 즉각적인 자금 확보 필요, 시설투자나 운전자금 필요, 저금리 대출 희망 |
