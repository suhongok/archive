## 1. 문제 정의 (Problem)

### 1.1 농업 노동력 위기

| 지표 | 수치 | 출처 |
|------|------|------|
| 농가 인구 (2024) | 216만 명 | 통계청 |
| 65세 이상 비율 | 49.8% | 통계청 |
| 10년간 농가 인구 감소 | -23% | 통계청 |
| 농업 임금 상승률 (연평균) | 5~7% | 농촌경제연구원 |
| 외국인 계절근로자 부족률 | 약 30% | 농림축산식품부 |

대한민국 농업은 **고령화 + 인력 부족 + 인건비 상승**이라는 구조적 위기에 직면해 있다.
특히 **노지(露地) 경작**은 시설원예와 달리 자동화가 극히 어려워, 여전히 수작업에 의존하고 있다.

### 1.2 노지 농업의 핵심 Pain Point

```
┌─────────────────────────────────────────────────────────┐
│  노지 농업 현장의 3대 고통                                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1️ 잡초 관리     → 연간 3~5회, 1ha당 30~50시간 소요     │
│                    제초제 과다 사용 → 환경 문제           │
│                                                         │
│  2️ 작물 모니터링  → 넓은 면적을 사람이 직접 순회          │
│                    병해충 조기 발견 어려움                │
│                                                         │
│  3️ 반복 운반     → 수확물, 자재를 사람이 직접 운반       │
│                    고령 농업인에게 큰 신체적 부담         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 기존 솔루션의 한계

| 기존 방식 | 문제점 |
|-----------|--------|
| 대형 농기계 (트랙터 등) | 소규모 밭에 부적합, 고가 (수천만~수억원) |
| 드론 방제 | 정밀도 낮음, 비행 규제, 배터리 한계 |
| 시설원예 자동화 | 노지에 적용 불가, 초기 투자 과다 |
| 해외 제초 로봇 (Naïo, FarmWise 등) | 국내 미출시, 수입 시 억대 가격, A/S 불가 |

**핵심 갭**: 국내 노지 환경에 맞는 **소형·저가·다기능** 자율이동 로봇이 전무하다.

## 2. 솔루션 (Solution)

### 2.1 제품 개요

**Robofarm 자율이동 플랫폼** — 노지 밭을 스스로 돌아다니며 다양한 농작업을 수행하는 모듈형 로봇

```
┌─────────────────────────────────────────────┐
│          Robofarm 자율이동 플랫폼              │
│                                             │
│   ┌───────────────────────────────────┐     │
│   │        작업 모듈 (교체 가능)        │     │
│   │  [제초] [운반] [파종] [모니터링]    │     │
│   └───────────┬───────────────────────┘     │
│               │ 표준 장착 인터페이스          │
│   ┌───────────┴───────────────────────┐     │
│   │        이동체 플랫폼 (공통)         │     │
│   │                                   │     │
│   │  ● 4륜/6륜 독립구동               │     │
│   │  ● GPS/RTK + LiDAR + 비전 센서    │     │
│   │  ● 자율주행 (SLAM + Navigation)    │     │
│   │  ● 지형인식 및 맵핑               │     │
│   │  ● ROS2 기반 소프트웨어            │     │
│   └───────────────────────────────────┘     │
│        ◯        ◯        ◯        ◯        │
│       농지용 대형 바퀴 (4WD/6WD)             │
└─────────────────────────────────────────────┘
```

### 2.2 핵심 차별화

| 항목 | Robofarm | 해외 경쟁제품 | 기존 농기계 |
|------|----------|-------------|-----------|
| **가격** | 1,500~3,000만원 | 5,000만원~2억원 | 3,000만원~수억원 |
| **크기** | 소형 (폭 1m 이하) | 중대형 | 대형 |
| **적용 범위** | 소규모 노지 밭 | 대규모 농장 | 대규모 농장 |
| **다기능** | 모듈 교체로 다용도 | 단일 기능 | 단일 기능 |
| **자율주행** | GPS/RTK + 비전 + LiDAR | GPS 위주 | 수동/반자동 |
| **A/S** | 국내 직접 대응 | 해외 의존 | 대리점 |

### 2.3 모듈형 설계 전략

**1단계 — 이동체 플랫폼 (현재 개발 중)**
- 자율주행 기반 이동체
- 표준 장착 인터페이스 (모듈 탈부착)
- 원격 모니터링/제어

**2단계 — 잡초 제거 모듈 (2026 하반기~2027)**
- AI 잡초 인식 (작물-잡초 구별)
- 정밀 분사 제초 (제초제 사용량 70~90% 절감)
- 글루포시네이트 암모늄 기반 (합법, 토양 잔류 없음)

**3단계 — 운반/파종 모듈 (2027~)**
- 수확물·자재 자율 운반
- 파종·이식 자동화
- 작물 상태 모니터링 (병해충 조기 발견)

## 3. 제품/서비스 상세

### 3.1 이동체 플랫폼 사양

| 구성요소 | 사양 | 비고 |
|----------|------|------|
| **프레임** | 알루미늄 프로파일 (4040) | 경량·고강성 |

| **MCU** | ESP32-S3 | 모터 제어, micro-ROS |
| **2D LiDAR** | RPLidar A2/A3 | 360° 장애물 감지 |
| **Depth Camera** | Orbbec Astra/Femto | 3D 환경 인식 |
| **GPS/RTK** | RTK GNSS 모듈 | cm급 위치 정밀도 |
| **IMU** | MPU9250 | 자세/방향 추정 |
| **통신** | WiFi + 4G LTE | 원격 모니터링 |
| **크기 (예상)** | 1,200 × 800 × 600mm | 밭 이랑 통행 가능 |
| **무게 (예상)** | 80~120kg (모듈 제외) | |
| **최대 적재** | 200kg | 모듈 + 작업물 |
| **방수** | IP65 | 야외 운용 |
