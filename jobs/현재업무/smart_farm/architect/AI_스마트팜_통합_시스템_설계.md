# AI 스마트팜 통합 시스템 설계

## 개요

본 문서는 ESP32 + Raspberry Pi 조합을 기반으로 카메라 모니터링, AI 생육 분석, AWS 클라우드 연동을 포함한 통합 스마트팜 시스템의 설계를 다룹니다.

## 2. 하드웨어 상세 설계

### 2.1 ESP32 (실시간 제어기)

#### 역할
- 모든 센서 데이터 수집 (1초 주기)
- 환경 제어 액추에이터 구동 (PID, 히스테리시스)
- 안전 감시 및 Fail-Safe 동작
- Raspberry Pi와 UART/I2C 통신

#### 핀 배치

```
ESP32 DevKit V1
─────────────────────────────────────────────
GPIO 21, 22 (I2C)    → SHT30 (온습도)
GPIO 16, 17 (UART2)  → MH-Z19B (CO₂)
GPIO 1, 3 (UART0)    → Raspberry Pi 통신
GPIO 32 (ADC1_CH4)   → pH 센서
GPIO 33 (ADC1_CH5)   → EC 센서
GPIO 25 (1-Wire)     → DS18B20 (양액 온도)
GPIO 26 (PWM)        → LED 드라이버
GPIO 27 (PWM)        → DC 팬
GPIO 12~19           → 8채널 릴레이
GPIO 34 (ADC1_CH6)   → 수위 센서
GPIO 35              → 비상 정지 버튼
```

### 2.2 Raspberry Pi 4/5 (엣지 서버)

#### 역할
- 카메라 스트리밍 (실시간 원격 확인)
- AI 생육 분석 (로컬 추론)
- 타임랩스 촬영 및 저장
- MQTT 브로커 (로컬)
- AWS 클라우드 게이트웨이

#### 하드웨어 구성

| 항목 | 권장 사양 | 비고 |
|------|----------|------|
| **보드** | Raspberry Pi 4 (4GB) 또는 Pi 5 | AI 처리용 |
| **카메라** | Pi Camera Module 3 또는 AI Camera (IMX500) | AI Camera 권장 |
| **저장장치** | 64GB microSD + 외장 SSD (256GB) | 타임랩스 저장 |
| **케이스** | 방열 팬 포함 | 장시간 가동 |

#### 카메라 옵션 비교

| 항목 | Pi Camera Module 3 | Raspberry Pi AI Camera |
|------|-------------------|------------------------|
| 센서 | Sony IMX708 | Sony IMX500 |
| 해상도 | 12MP | 12.3MP |
| AI 가속 | 없음 (Pi CPU 사용) | 온칩 AI 가속기 내장 |
| 추론 속도 | 5~10 fps | 30+ fps |
| 가격 | ~₩40,000 | ~₩95,000 |
| 권장 | 비용 절약 시 | AI 분석 중심 시 ⭐ |

### 3.3 스트리밍 서버 구성

```python
# Raspberry Pi 스트리밍 서버 (간략화)

# 방법 1: WebRTC (권장 - 저지연)
# - 라이브러리: aiortc
# - 장점: 양방향, 저지연 (<500ms)
# - 클라우드: AWS Kinesis Video Streams 연동

# 방법 2: RTSP
# - 라이브러리: picamera2 + GStreamer
# - 장점: 표준 프로토콜, VLC로 재생 가능

# 방법 3: HTTP Live Streaming (HLS)
# - 라이브러리: ffmpeg
# - 장점: 브라우저 호환성
# - 단점: 지연 5~30초
```

## 4. AI 생육 분석 시스템

### 4.1 분석 항목

| 분석 항목 | 목적 | AI 모델 | 정확도 목표 |
|----------|------|---------|------------|
| **잎 면적 측정** | 성장률 추정 | 세그멘테이션 (U-Net) | 95% |
| **잎 색상 분석** | 영양 상태 판단 | 색상 히스토그램 + ML | 90% |
| **병해충 감지** | 조기 발견 | 객체 탐지 (YOLOv8) | 85% |
| **성장 단계 분류** | 수확 시기 예측 | 분류 (MobileNet) | 90% |
| **팁번 감지** | 환경 문제 조기 감지 | 객체 탐지 | 90% |

### 4.4 잎 분석 상세

#### 색상 기반 건강 지표

```python
# 색상 분석 기준 (HSV 색공간)

건강한 잎:
- H: 35~85 (녹색~황록색)
- S: 40~100 (채도 적정)
- V: 40~100 (명도 적정)

영양 결핍 징후:
┌──────────────┬─────────────────┬──────────────┐
│    증상      │    색상 변화     │   추정 원인   │
├──────────────┼─────────────────┼──────────────┤
│ 전체 황화    │ H↑ (황색화)      │ 질소 결핍    │
│ 잎맥 간 황화 │ H↑, 잎맥 유지    │ 철/마그네슘  │
│ 잎끝 갈변    │ V↓, 갈색        │ 팁번 (Ca)    │
│ 반점        │ 국소적 변색      │ 병해         │
└──────────────┴─────────────────┴──────────────┘

분석 결과 액션:
- 황화 감지 → EC 확인 및 양액 보충 권고
- 팁번 감지 → 환기 강화 및 온도 낮춤
- 병해 의심 → 격리 및 클라우드 정밀 분석
```

### 4.5 성장률 모니터링

```python
# 잎 면적 기반 성장률 계산

매일 분석:
1. 상단 뷰 이미지에서 잎 영역 세그멘테이션
2. 픽셀 카운트 → 실제 면적 변환 (cm²)
3. 전일 대비 성장률 계산

leaf_area_today = segment_leaves(image)  # cm²
growth_rate = (leaf_area_today - leaf_area_yesterday) / leaf_area_yesterday * 100

정상 성장률 기준 (상추):
- 발아 후 1주: 10~15%/일
- 2~3주: 8~12%/일
- 4주 이후: 5~8%/일

이상 감지:
- 성장률 < 3%: "성장 둔화" 알림
- 성장률 < 0%: "성장 멈춤" 긴급 알림
```

#### 센서 데이터 (실시간)

```
ESP32 → Pi → AWS IoT Core → IoT Rules
                               │
              ┌────────────────┼────────────────┐
              ▼                ▼                ▼
         DynamoDB         Lambda           Kinesis
        (실시간 조회)    (이상 감지)      (버퍼링)
                            │                │
                            ▼                ▼
                          SNS              S3
                        (알림)          (장기 저장)
```

```

                                        │
                        ┌───────────────┼───────────────┐
                        ▼               ▼               ▼
                    Rekognition    SageMaker        DynamoDB
                   (라벨링)       (커스텀 AI)      (메타데이터)
```
