# 실내 상추 재배기 환경제어 시스템 설계

## 개요

본 문서는 실내 상추 재배기 제작을 위한 환경 조건과 제어 방법을 정리한 것입니다. 각 환경 요소별로 목표값, 센서, 액추에이터, 제어 로직을 상세히 기술합니다.

---

## 1. 환경 제어 요소 총괄표

| 환경 요소 | 목표값 | 센서 | 액추에이터 | 제어 방식 |
|----------|--------|------|-----------|----------|
| **온도** | 20~23℃ (주간) / 15~18℃ (야간) | DHT22, DS18B20 | 펠티어 쿨러, 히터, 팬 | PID 제어 |
| **습도** | 60~70% | DHT22, SHT30 | 초음파 가습기, 제습팬 | 히스테리시스 |
| **CO₂** | 600~900 ppm | MH-Z19B, SCD40 | CO₂ 솔레노이드 밸브, 환기팬 | 임계값 제어 |
| **광(LED)** | PPFD 110~150 μmol/m²/s | 조도센서 (BH1750) | LED 드라이버 (PWM) | 타이머 + PWM |
| **양액 pH** | 5.5~6.5 | pH 센서 (E-201C) | pH Up/Down 펌프 | PID 제어 |
| **양액 EC** | 1.2~1.6 dS/m | EC 센서 (DFRobot) | 양액/원수 펌프 | 비례 제어 |
| **양액 온도** | 19~21℃ | DS18B20 (방수) | 수중 히터, 쿨러 | PID 제어 |
| **공기 유동** | 0.3 m/s 이상 | 풍속센서 (선택) | DC 팬 | 상시 가동 |

## 2. 각 환경 요소별 상세 설계

### 2.1 온도 제어

#### 목표값
- **주간**: 20~23℃
- **야간**: 15~18℃
- **허용 오차**: ±2℃

#### 센서 선택

| 센서 | 정밀도 | 특징 | 권장도 |
|------|--------|------|--------|
| **DHT22** | ±0.5℃ | 온습도 동시 측정, 저가 | ⭐⭐ |
| **SHT30** | ±0.3℃ | I2C, 고정밀, 습도 동시 측정 | ⭐⭐⭐ |
| **DS18B20** | ±0.5℃ | 1-Wire, 방수형 가능 | ⭐⭐ |

#### 액추에이터

| 장치 | 용도 | 제어 방식 | 비고 |
|------|------|----------|------|
| **펠티어 모듈** | 냉각/가열 | PWM | 소형 재배기에 적합 |
| **DC 쿨링팬** | 방열/냉각 | PWM | 펠티어와 함께 사용 |
| **PTC 히터** | 가열 | 릴레이 ON/OFF | 야간 온도 유지 |
| **환기팬** | 열 배출 | 릴레이 | 고온 시 작동 |

#### 제어 로직

```
[온도 제어 알고리즘]

1. 센서로 현재 온도 측정 (1초 간격)
2. 시간대 확인 (주간/야간)
   - 주간 (06:00~22:00): 목표 21.5℃
   - 야간 (22:00~06:00): 목표 16.5℃

3. PID 제어 적용
   - Kp = 2.0, Ki = 0.5, Kd = 1.0 (튜닝 필요)

4. 출력 결정
   - 출력 > 0: 히터 PWM 제어
   - 출력 < 0: 쿨러 PWM 제어
   - |출력| < 임계값: 대기

5. 안전 장치
   - 온도 > 30℃: 긴급 환기팬 작동
   - 온도 < 10℃: 긴급 히터 작동
```

---

### 2.2 습도 제어

#### 목표값
- **일반**: 60~70%
- **허용 범위**: 50~80%

#### 센서 선택

| 센서 | 정밀도 | 특징 |
|------|--------|------|
| **DHT22** | ±2~5% | 온도 동시 측정 |
| **SHT30** | ±2% | I2C, 고정밀 |
| **BME280** | ±3% | 온도/습도/기압 |

#### 액추에이터

| 장치 | 용도 | 제어 방식 |
|------|------|----------|
| **초음파 가습기 모듈** | 가습 | 릴레이 ON/OFF |
| **제습 팬** | 제습 | 릴레이 |
| **환기 팬** | 습도 조절 | PWM |

#### 제어 로직

```
[습도 제어 알고리즘 - 히스테리시스 방식]

설정값:
- 가습 시작: 55%
- 가습 종료: 65%
- 제습 시작: 75%
- 제습 종료: 68%

1. 현재 습도 측정
2. 상태 판단
   - 습도 < 55%: 가습기 ON
   - 습도 > 65% (가습 중): 가습기 OFF
   - 습도 > 75%: 환기팬 ON (제습)
   - 습도 < 68% (제습 중): 환기팬 OFF
```

---

### 2.3 CO₂ 농도 제어

#### 목표값
- **일반**: 600~900 ppm
- **광합성 촉진**: 800~1000 ppm
- **야간**: 제어 불필요 (광합성 없음)

#### 센서 선택

| 센서 | 측정 범위 | 정밀도 | 가격대 | 권장도 |
|------|----------|--------|--------|--------|
| **MH-Z19B** | 0~5000 ppm | ±50 ppm | 저가 | ⭐⭐⭐ |
| **SCD40** | 0~40000 ppm | ±50 ppm | 중가 | ⭐⭐⭐ |
| **CM1106** | 0~5000 ppm | ±30 ppm | 중가 | ⭐⭐ |

#### 액추에이터

| 장치 | 용도 | 제어 방식 |
|------|------|----------|
| **CO₂ 솔레노이드 밸브** | CO₂ 공급 | 릴레이 |
| **CO₂ 캔/봄베** | CO₂ 공급원 | - |
| **환기팬** | CO₂ 배출 | 릴레이/PWM |

#### 제어 로직

```
[CO₂ 제어 알고리즘]

전제: 주간(LED ON)에만 CO₂ 제어

1. LED 상태 확인
   - LED OFF (야간): CO₂ 제어 비활성화

2. 현재 CO₂ 농도 측정 (30초 간격)

3. 제어 로직
   - CO₂ < 600 ppm: 솔레노이드 밸브 OPEN (3초)
   - CO₂ > 1000 ppm: 환기팬 ON
   - 600~900 ppm: 유지

4. 안전 장치
   - CO₂ > 1500 ppm: 긴급 환기
   - 밸브 작동 후 최소 60초 대기 (과공급 방지)
```

---

### 2.4 광(LED) 제어

#### 목표값
- **PPFD**: 110~150 μmol/m²/s
- **광주기**: 12~16시간 (조절 가능)
- **LED 비율**: Red:Blue = 6:4 ~ 8:2

#### 구성 요소

| 항목 | 사양 | 비고 |
|------|------|------|
| **LED 타입** | Full Spectrum 또는 R:B 혼합 | 적색 660nm, 청색 450nm |
| **전력** | 20~40W (재배 면적 0.1m² 기준) | 면적에 비례 |
| **드라이버** | Mean Well LPF 시리즈 | PWM 디밍 지원 |
| **조도 센서** | BH1750 (lux) | 참고용 |

#### 광원 배치

```
[LED 배치 예시 - 30cm x 30cm 재배 면적]

┌─────────────────────────┐
│  ◉ Red   ◉ Blue  ◉ Red │
│                         │
│  ◉ Blue  ◉ Red   ◉ Blue│  LED 높이: 식물에서 15~20cm
│                         │
│  ◉ Red   ◉ Blue  ◉ Red │
└─────────────────────────┘

Red LED: 6개 (660nm, 3W)
Blue LED: 3개 (450nm, 3W)
총: 27W
```

#### 제어 로직

```
[LED 제어 알고리즘]

설정값:
- 점등 시작: 06:00
- 소등 시간: 22:00 (16시간 광주기)
- PWM 범위: 0~100%

1. RTC로 현재 시간 확인

2. 시간대별 제어
   - 06:00~06:30: 점진적 점등 (0→100%, 일출 효과)
   - 06:30~21:30: 100% 유지
   - 21:30~22:00: 점진적 소등 (100→0%, 일몰 효과)
   - 22:00~06:00: OFF

3. 생육 단계별 조절 (선택)
   - 발아기: 50% 밝기
   - 생육기: 100% 밝기
```

### 2.5 양액 pH 제어

#### 목표값
- **최적**: 5.5~6.0
- **허용 범위**: 5.0~6.5

#### 센서 선택

| 센서 | 측정 범위 | 정밀도 | 주의사항 |
|------|----------|--------|----------|
| **E-201C (BNC)** | 0~14 pH | ±0.1 | 정기 교정 필요 |
| **DFRobot Gravity** | 0~14 pH | ±0.1 | 아두이노 호환 |
| **Atlas Scientific** | 0~14 pH | ±0.002 | 고정밀, 고가 |

#### 액추에이터

| 장치 | 용도 | 비고 |
|------|------|------|
| **연동 펌프 (pH Down)** | 산성 용액 투입 | 인산, 질산 |
| **연동 펌프 (pH Up)** | 염기성 용액 투입 | 수산화칼륨 |
| **교반기** | 양액 혼합 | DC 모터 |

#### 제어 로직

```
[pH 제어 알고리즘]

설정값:
- 목표 pH: 5.8
- 허용 범위: 5.5~6.1
- 데드밴드: ±0.3

1. pH 센서로 측정 (5분 간격)

2. 제어 판단
   - pH > 6.1: pH Down 펌프 작동 (1ml 투입)
   - pH < 5.5: pH Up 펌프 작동 (1ml 투입)
   - 5.5~6.1: 유지

3. 투입 후 처리
   - 교반기 30초 작동
   - 3분 대기 (안정화)
   - 재측정

4. 안전 장치
   - 1시간 내 최대 10회 투입 제한
   - pH < 4.0 또는 pH > 8.0: 알람
```

---

### 2.6 양액 EC 제어

#### 목표값
- **상추**: 1.2~1.6 dS/m (mS/cm)
- **여름**: 1.2 dS/m (낮게)
- **겨울**: 1.6 dS/m (높게)

#### 센서 선택

| 센서 | 측정 범위 | 정밀도 |
|------|----------|--------|
| **DFRobot Gravity EC** | 0~20 mS/cm | ±5% |
| **Atlas Scientific K1.0** | 0.1~100 mS/cm | ±2% |

#### 액추에이터

| 장치 | 용도 |
|------|------|
| **연동 펌프 (A액)** | 농축 양액 A 투입 |
| **연동 펌프 (B액)** | 농축 양액 B 투입 |
| **연동 펌프 (원수)** | 희석용 물 투입 |

#### 제어 로직

```
[EC 제어 알고리즘]

설정값:
- 목표 EC: 1.4 mS/cm
- 허용 범위: 1.2~1.6

1. EC 센서로 측정 (10분 간격)

2. 제어 판단
   - EC < 1.2: A액, B액 펌프 작동 (동시에 같은 비율)
   - EC > 1.6: 원수 펌프 작동 (희석)
   - 1.2~1.6: 유지

3. 투입량 계산 (비례 제어)
   - 편차 = 목표 EC - 현재 EC
   - 투입량 = Kp × 편차 × 탱크 용량

4. 안전 장치
   - 탱크 수위 센서 연동
   - EC > 3.0: 알람 (과농축)
```

#### 목표값
- **최적**: 19~21℃
- **허용 범위**: 18~23℃

#### 센서
- **DS18B20 방수형**: 양액에 직접 침수 가능

#### 액추에이터

| 장치 | 용도 |
|------|------|
| **수중 히터 (50W)** | 가열 |
| **펠티어 수냉 시스템** | 냉각 |
| **수중 펌프** | 양액 순환 |

#### 제어 로직

```
[양액 온도 제어]

1. 온도 측정 (30초 간격)

2. 제어
   - 온도 < 18℃: 수중 히터 ON
   - 온도 > 22℃: 냉각 시스템 ON
   - 18~22℃: 유지

3. 순환
   - 양액 펌프 15분 ON / 15분 OFF (간헐 순환)
```

### 2.8 공기 유동 제어

#### 목표값
- **풍속**: 0.3 m/s 이상 (팁번 방지)

#### 구성

| 장치 | 사양 | 비고 |
|------|------|------|
| **DC 팬** | 80mm, 12V | 저소음 선택 |
| **PWM 제어** | 30~100% | 풍량 조절 |

#### 제어 로직

```
[공기 유동 제어]

1. 기본: 상시 가동 (PWM 50%)

2. 조건부 증속

   - 온도 > 25℃: PWM 100%

3. 야간 (선택)
   - PWM 30% (저소음 모드)
```

## 5. 소프트웨어 구조

### 5.1 펌웨어 구조

```
[메인 루프 구조]

void loop() {
    // 1. 센서 읽기 (비동기)
    readSensors();          // 1초 주기

    // 2. 환경 제어
    controlTemperature();   // PID
    controlHumidity();      // 히스테리시스
    controlCO2();           // 임계값
    controlLED();           // 타이머 + PWM
    controlNutrient();      // pH, EC 제어
    controlAirFlow();       // PWM

    // 3. 데이터 로깅
    logData();              // 1분 주기

    // 4. 통신
    handleMQTT();           // 원격 모니터링
    handleOTA();            // 펌웨어 업데이트
}
```

### 5.2 태스크 스케줄링 (FreeRTOS)

| 태스크 | 주기 | 우선순위 | 코어 |
|--------|------|----------|------|
| 센서 읽기 | 1초 | 높음 | Core 0 |
| 환경 제어 | 5초 | 높음 | Core 0 |

## 6. 안전 및 알람 시스템

### 6.1 알람 조건

| 조건 | 레벨 | 동작 |
|------|------|------|
| 온도 > 30℃ 또는 < 10℃ | 경고 | LED 점멸, 앱 알림 |
| pH < 4.5 또는 > 7.5 | 위험 | 펌프 정지, 알람 |
| EC > 3.0 mS/cm | 위험 | 양액 펌프 정지 |
| 수위 부족 | 경고 | 순환 펌프 정지 |
| 센서 오류 | 위험 | 해당 제어 중단 |

### 6.2 Fail-Safe 동작

```
[비상 시 기본 동작]

1. 센서 오류 시
   - 해당 액추에이터 OFF
   - 수동 모드 전환
   - 알람 발생

2. 통신 두절 시
   - 마지막 설정값으로 자율 운전
   - 로컬 디스플레이에 상태 표시

3. 정전 복구 시
   - EEPROM에서 설정 복원
   - 점진적 재시작 (LED 서서히 점등)
```
