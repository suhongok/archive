# SF 스토리텔링 유튜브 제작 전략

## 프로젝트 개요

**콘텐츠 형식:** 스토리텔링 낭독 (내레이션 + 배경 이미지/영상)
**현재 단계:** 시놉시스 완성
**예산:** 소규모 (월 구독 서비스 활용 가능)

---

## 1. 제작 파이프라인

```
시놉시스 → 에피소드 스크립트 → 음성(TTS) → 배경 이미지/영상 → 배경음악 → 편집 → 업로드
```

---

## 2. 각 요소별 추천 도구 및 전략

### 2.1 스크립트 작성

**목표:** 시놉시스를 낭독용 스크립트로 확장

| 도구 | 용도 | 비용 |
|------|------|------|
| Claude | 스크립트 확장, 대화 작성, 분위기 묘사 | 무료/유료 |
| Google Docs | 스크립트 관리 및 수정 | 무료 |

**팁:**
- 에피소드당 8~15분 분량 (약 2,000~3,500자) 권장
- 청각 콘텐츠이므로 시각 묘사보다 **감정과 분위기** 위주로 작성
- 문장을 짧게 끊어 TTS 발화에 최적화

---

### 2.2 음성 TTS

**추천 도구 (한국어 지원):**

| 도구 | 특징 | 비용 |
|------|------|------|
| **CLOVA Voice** | 자연스러운 한국어, 다양한 목소리 | 월 약 15,000원~ |
| **TypeCast** | 감정 표현 가능, 캐릭터별 목소리 | 월 약 20,000원~ |
| **ElevenLabs** | 고품질, 영어 우수/한국어 지원 | 월 약 $5~ |
| **VREW** | 무료, 자막+TTS 동시 생성 | 무료/유료 |

**전략:**
1. **단일 내레이터 스타일:** 한 목소리로 전체 진행 (비용 절감, 일관성)
2. **캐릭터별 목소리:** 주요 캐릭터 2~3개 목소리 구분 (TypeCast 추천)
3. **하이브리드:** 내레이션은 TTS, 핵심 대사만 직접 녹음

**추천:** 초기에는 CLOVA Voice나 VREW로 시작, 채널 성장 시 TypeCast로 업그레이드

---

### 2.3 배경 이미지

**AI 이미지 생성 도구:**

| 도구 | 특징 | 비용 |
|------|------|------|
| **Midjourney** | SF에 최적, 고품질 | 월 $10~ |
| **DALL-E 3** | ChatGPT Plus 포함, 사용 편리 | 월 $20 (ChatGPT Plus) |
| **Leonardo AI** | 무료 크레딧 넉넉, SF 스타일 우수 | 무료/유료 |
| **Stable Diffusion** | 무료, 로컬 실행 가능 | 무료 (GPU 필요) |

**이미지 전략:**

```
1개 에피소드 (10분) 기준 이미지 구성:
├── 메인 장면: 5~8장 (핵심 전환점마다)
├── 분위기 컷: 3~5장 (배경, 우주, 도시 등)
└── 캐릭터 초상: 2~3장 (주요 등장인물)
```

**프롬프트 팁 (SF용):**
```
cinematic, sci-fi, [장면 묘사],
dramatic lighting, futuristic,
concept art style, 8k, detailed
```

**추천:** Leonardo AI (무료 시작) → 성장 후 Midjourney

---

### 2.4 애니메이션/모션 효과

**정적 이미지에 움직임 추가:**

| 도구 | 기능 | 비용 |
|------|------|------|
| **CapCut** | 켄번스 효과, 전환, 자막 | 무료 |
| **Canva** | 간단한 애니메이션, 전환 효과 | 무료/유료 |
| **After Effects** | 고급 모션 그래픽 | 월 약 24,000원 |
| **Pika Labs / Runway** | AI 영상 생성 (이미지→영상) | 유료 |

**움직임 전략:**
1. **켄번스 효과:** 이미지 줌인/아웃, 패닝 (기본)
2. **파티클 효과:** 먼지, 빛, 별 등 오버레이
3. **글리치 효과:** SF 분위기 강조용 전환
4. **AI 모션:** Runway Gen-2로 이미지에 미세한 움직임 추가

**추천:** CapCut으로 시작 (무료, 기능 충분)

---

### 2.5 배경음악 (BGM)

**저작권 안전한 음원 소스:**

| 플랫폼 | 특징 | 비용 |
|------|------|------|
| **Epidemic Sound** | 고품질, SF/앰비언트 풍부 | 월 약 15,000원~ |
| **Artlist** | 무제한 다운로드, 상업용 | 연 약 200,000원 |
| **YouTube Audio Library** | 무료, 수익화 가능 | 무료 |
| **Pixabay Music** | 무료, 다양한 장르 | 무료 |
| **Suno AI** | AI 음악 생성 | 무료/유료 |

**BGM 구성 전략:**

```
에피소드 음악 구성:
├── 메인 테마: 채널 아이덴티티용 (인트로/아웃트로)
├── 텐션 BGM: 긴장감 있는 장면용
├── 감성 BGM: 감정적 장면용
└── 앰비언트: 배경 깔림음 (우주 소음, 기계음 등)
```

**추천:** YouTube Audio Library + Pixabay (무료 시작) → Epidemic Sound (성장 후)

## 3. 예산별 도구 조합

### 무료 조합 (월 0원)
- 스크립트: Claude 무료
- TTS: VREW 무료 티어
- 이미지: Leonardo AI 무료
- 편집: CapCut 무료
- BGM: YouTube Audio Library + Pixabay

### 소규모 예산 (월 3~5만원) ⭐ 추천
- 스크립트: Claude Pro (약 20,000원)
- TTS: CLOVA Voice 기본 (약 15,000원)
- 이미지: Leonardo AI 유료 또는 Midjourney 기본
- 편집: CapCut 무료
- BGM: YouTube Audio Library + Pixabay

### 중간 예산 (월 10만원+)
- TTS: TypeCast (감정 표현)
- 이미지: Midjourney 표준
- BGM: Epidemic Sound
- 편집: CapCut Pro 또는 Premiere Pro

## 4. 제작 워크플로우 (에피소드당)

### Day 1: 스크립트
1. 시놉시스에서 해당 에피소드 부분 추출
2. Claude로 낭독 스크립트 확장
3. 장면 전환점 마킹 (이미지 필요 지점)

### Day 2: 에셋 준비
1. 장면별 이미지 프롬프트 작성
2. AI로 이미지 생성 (장면당 2~3개 생성 후 선택)
3. TTS로 음성 생성

### Day 3: 편집
1. CapCut에서 음성 배치
2. 타이밍에 맞춰 이미지 배치
3. 켄번스 효과, 전환 추가
4. BGM 및 효과음 추가
5. 자막 추가 (선택)

### Day 4: 검수 및 업로드
1. 최종 검수
2. 썸네일 제작
3. 제목, 설명, 태그 작성
4. 업로드 및 예약

---

## 5. 채널 브랜딩 요소

### 필수 에셋
- **채널 로고:** SF 세계관 상징 (AI로 생성 가능)
- **인트로 영상:** 5~10초 (세계관 소개)
- **아웃트로 영상:** 구독 유도, 다음 에피소드 예고
- **썸네일 템플릿:** 일관된 스타일 유지
- **메인 테마 BGM:** 채널 아이덴티티

### 썸네일 전략
- 핵심 장면 이미지 사용
- 에피소드 번호 명시
- 강렬한 한 줄 카피 (호기심 유발)

---

## 6. 성장 전략

### 초기 (0~1,000 구독자)
- 주 1회 업로드로 일관성 유지
- 짧은 클립 (Shorts)으로 유입 유도
- SF 커뮤니티에 공유

### 성장기 (1,000~10,000 구독자)
- 주 2회로 업로드 빈도 증가
- 시청자 피드백 반영
- 세계관 해설 영상 추가

### 안정기 (10,000+ 구독자)
- 제작 품질 업그레이드
- 멤버십/후원 도입
- 굿즈, 소설 출판 등 확장
