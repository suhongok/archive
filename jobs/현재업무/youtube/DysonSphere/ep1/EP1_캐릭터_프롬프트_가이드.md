## 캐릭터 일관성 시스템

### 미드저니에서 캐릭터 일관성 유지 방법

1. **캐릭터 레퍼런스 (--cref)**: 생성된 캐릭터 이미지 URL 사용
   ```
   [프롬프트] --cref [이미지URL] --cw 100
   ```

2. **시드 고정 (--seed)**: 첫 생성 시 시드 번호 저장 후 재사용
   ```
   [프롬프트] --seed 12345
   ```

3. **동일 키워드 반복**: 모든 프롬프트에 캐릭터 핵심 특징 포함

| 김해성 | 다크블루 + 오렌지 | 따뜻한 램프 + 차가운 화면 | 희망적 고독 |
| 지구 앵커 | 네이비 + 사이언 | 차가운 스튜디오 조명 | 차갑고 통제됨 |
| 화성 앵커 | 오렌지 + 브라운 | 따뜻하지만 거친 조명 | 저항과 분노 |
| 금성 의장 | 화이트 + 골드 | 부드러운 황금빛 | 지혜와 고뇌 |
| 미지의 존재 | 사이언 + 순수 검정 | 눈빛 발광만 | 신비와 위협 |
| 아버지 | 따뜻한 톤 (과거) | 따뜻한 자연광 | 그리움과 상실 |

## 캐릭터 일관성 워크플로우

### 1단계: 캐릭터 시트 생성
각 캐릭터의 "캐릭터 시트" 프롬프트로 기본 디자인 확정

### 2단계: 시드 번호 저장
마음에 드는 결과의 시드 번호 기록
```
/imagine [프롬프트] → 결과 이미지 우클릭 → Job ID 확인
```

### 3단계: 캐릭터 레퍼런스 사용
확정된 캐릭터 이미지를 다른 장면에 적용
```
[새 장면 프롬프트] --cref [캐릭터시트 URL] --cw 80
```

### 4단계: 스타일 레퍼런스 추가 (선택)
전체 작품 톤 통일을 위해
```
[프롬프트] --sref [스타일 이미지 URL] --sw 50
```

## 추가 팁

### 표정 일관성
동일 캐릭터의 다른 표정 생성 시:
```
[기존 캐릭터 키워드] + [새로운 표정: shocked/sad/angry/happy]
--cref [원본 이미지] --cw 100
```

### 의상 변경
같은 캐릭터 다른 옷:
```
[기존 캐릭터 키워드] + [새로운 의상 설명]
--cref [원본 이미지] --cw 70
```
(--cw를 낮추면 얼굴은 유지하면서 의상 변경 가능)

### 나이 변화 (회상/미래)
```
[기존 캐릭터 키워드] + younger version, age 10
또는
[기존 캐릭터 키워드] + older version, age 30
--cref [원본 이미지] --cw 50
```
