# PART 1: 주요 캐릭터

## 김해성 (Kim Haesung) - 주인공

### 기본 정보
- **나이:** 18세 (시즌1) → 20세 (시즌2 종료)
- **직업:** CyberNetworks 수습 기술자 (고아원 출신)
- **역할:** 양(陽)의 계승자, 빛의 계승자
- **거주지:** 서울 외곽 소형 아파트

### 외모
- 짧은 검은 머리
- 결연하면서도 순수한 눈빛
- 수습 기술자 유니폼, 툴벨트 착용

### 성격 변화
| 시점 | 성격 |
|------|------|
| 원래 | 밝고 활달함 |
| 시즌1 초반 | 어둡고 삐뚤어짐, 불신 |
| 시즌1 후반 | 각성, 책임감 형성 |
| 시즌2 | 성숙, 용서, 리더십 |

### 가족 관계
- **아버지 김민준:** 다이슨 스피어 수석 연구원, 대재앙 때 실종 (사망 추정 → 실제로는 동면/디지털화 상태로 다이슨 스피어 내부에 존재)
- **할아버지 김현인:** 다이슨 스피어 완성의 리더, 최고 관리자

### 6단계 성장 여정

| 단계 | 명칭 | 핵심 질문 | 에피소드 |
|------|------|----------|----------|
| 1 | 눈뜸 (Awakening) | "이건 뭐지?" | S1 EP1~3 |
| 2 | 부름 (The Calling) | "왜 나야?" | S1 EP4~6 |
| 3 | 수련 (Training) | "이 분노를 어쩌지?" | S1 EP7~12 |
| 4 | 단련 (Tempering) | "이 고통을 어떻게?" | S2 EP1~6 |
| 5 | 깨달음 (Enlightenment) | "진짜 답은 뭐지?" | S2 EP7~10 |
| 6 | 새벽 (New Dawn) | "우리는 어디로?" | S2 EP11~12 |

## 김민준 (Kim Minjun) - 해성의 아버지

### 기본 정보
- **역할:** 다이슨 스피어 수석 연구원
- **전문 분야:** 바이오-양자 통신, 신경 인터페이스

### 상태 (수정된 설정)
- **공식 기록:** "실종 - 2124년 대재앙, 사망 추정"
- **실제 상태:** 다이슨 스피어 내부에서 **동면/디지털화 상태**로 존재
- 시신은 발견되지 않음
- 해성에게 "네 아버지는 살아있다"는 메시지가 전달됨

### 스토리적 의미
- 시즌2에서 재회 가능성
- 단순 사망이 아닌 "기다리고 있다"는 설정으로 희망 부여

# PART 2: 기술 설정

## 기술 등급 분류

| 등급 | 상태 | 접근성 |
|------|------|--------|
| 🟢 상용화 | Commercialized | 누구나 구매 가능 |
| 🟡 제한적 | Limited | 정부/기업/부유층만 |
| 🔴 로스트 테크 | Lost Tech | 접근 불가, 재현 불가 |

---

## 핵심 기술 (Core Technologies)

### 🔴 바이오-양자 통신 (Bio-Quantum Communication)
- **등급:** 로스트 테크
- **기능:** 뇌파와 양자 얽힘 연결, 무제한 거리 실시간 통신
- **특징:** 해성 아버지 김민준의 연구 분야
- **스토리 의미:** 다이슨 스피어 재가동 시 복원 → 인류 통합의 열쇠

### 🟢 소형 핵분열 전지 (Compact Fission Cell)
- **등급:** 상용화
- **크기:** 배낭 크기
- **출력:** 50kW급
- **수명:** 10-15년
- **용도:** 일상 전력원

### 🟢 이온추진 엔진 (Ion Propulsion Engine)
- **등급:** 상용화
- **최대 속도:** 50km/s
- **용도:** 행성 간 이동 표준
- **예시:** 지구-화성 2.8~12.5주

### 🟢/🟡 클라우드 통신 (Cloud Communication)
- **등급:** 상용화 (기본) / 제한적 (양자)
- **기본:** 광속 기반, 지연 있음
- **양자:** 실시간, 고가로 제한적

### 🟡 인공 중력 링 (Artificial Gravity Ring)
- **원리:** 원심력으로 중력 모사

### 🔴 신경 인터페이스 (Neural Interface)
- **등급:** 로스트 테크
- **기능:** 뇌-컴퓨터 직접 연결
- **연구자:** 김민준 박사

## AI/컴퓨팅 기술

### 🟢 분산 AI (Distributed AI)
- **특징:** 통신 지연으로 각 행성별 독립 AI
- **성향:** 지구(보수적), 화성(실용적), 금성(창의적)

### 🟡 양자 컴퓨팅 (Quantum Computing)
- **조건:** 다이슨 스피어 내부 초저온 환경에서만 작동
- **스토리:** 오라클의 진짜 "두뇌"

### 🟢 홀로그램 통신 (Holographic Communication)
- **기능:** 3D 영상 투사
- **한계:** 통신 지연은 그대로 적용

### 🟢 소행성 채굴 (Asteroid Mining)
- **주기:** 2-3년/회
- **산출:** 희귀 금속
- **한계:** 화성은 운송비로 혜택 제한

- **출력:** 1GW급

- **스토리:** 다이슨 스피어가 유일한 답인 이유

### 🟢 태양광 집적 위성 (Solar Power Satellite)
- **출력:** 100MW급
- **효율:** 20%
- **의미:** 다이슨 스피어의 "축소판"

## 세계관 기술적 갈등 구조

1. **로스트 테크의 공백:** 바이오-양자 통신, 신경 인터페이스 유실 → 인류 분열
2. **기술 격차:** 핵심 기술은 소수만 접근 → 빈부/세력 격차
3. **통신의 한계:** 광속 지연으로 실시간 협력 불가 → 분산 AI 필요
4. **다이슨 스피어의 의미:** 단순 에너지가 아닌, 양자통신 + 양자컴퓨팅 복원 = 인류 통합의 열쇠
