## 📝 사람 정보 업데이트 가이드라인

### 기본 구조

각 사람 파일은 다음 섹션을 포함합니다:

```markdown
# [이름]

**만난 날짜**: [날짜]  
**현재 직장**: [직장명]  
**지역/기타**: [정보]

## 👤 기본 정보
(테이블 형식으로 주요 정보)

## 🎯 특징
(성격, 태도, 특이사항)

## 💼 직업 정보
(직장, 직위, 전공, 경력)

## 📞 연락 정보
(연락처, SNS, 마지막 연락)

## 💡 협력 가능성
(분야, 강점, 주의사항, 추천 주기)

## 📝 회고 및 메모
(첫 만남, 인상 깊은 점, 협력 평가)

## 🔗 관련 정보
(링크)
```

**필수 항목:**

| 항목 | 입력 방식 | 예시 |
|------|---------|------|
| 이름 | 정확한 이름 | 홍길동 |
| 만난 날짜 | `YYYY.MM.DD` | 2025.12.27 |
| 직장 | 회사명 + 직위 | 삼성전자 (개발팀) |
| 성격/태도 | 한두 줄 요약 | 밝고 외향적 |
| 지역 | 거주지, 출신지 | 서울 → 대전D` 형식 |
| 직장 | 회사명 (부서명) |
| 성격/태도 | 한두 줄 요약 |
| 지역/기타 | 거주지, 출신지 등 |

### ✅ 사람 추가 절차

#### Step 1: 새 파일 생성
```bash
# 새로운 사람을 만났을 때
# /archive/people/[이름].md 파일 생성
```

#### Step 2: 기본 템플릿 작성
```markdown
# [이름]

**만난 날짜**: [YYYY년 MM월 DD일]  
**현재 직장**: [직장명]

## 👤 기본 정보
...
```

#### Step 3: 각 섹션 작성
- 위 가이드라인 참조하여 작성
- 모르는 정보는 "(미기록)" 표시

#### Step 4: 목록.md 업데이트
1. [목록.md](목록.md) 파일 열기
2. 아래 위치에 링크 추가:
   - 직장/조직별 섹션에 추가
   - 협력도 랭킹에 추가 (필요시)

#### Step 5: Git 커밋
```bash
git add people/
git commit -m "Add [이름] profile"
git push
```
