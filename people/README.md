## 📋 주요 내용

### 인맥 관리
- 이름, 만난 날짜
- 직장 및 직위
- 개인적 특징 및 경험
- 협력 가능성 평가
- 정기 연락 주기

### 기록 대상
- 전문가 및 동료
- 협력 가능 인물
- 멘토/네트워크

---

## 📝 사람 정보 업데이트 가이드라인

### 기본 구조

각 사람 파일은 다음 섹션을 포함합니다:

```markdown
# [이름]

**만난 날짜**: [날짜]  
**현재 직장**: [직장명]  
**지역/기타**: [정보]

## 👤 기본 정보
(테이블 형식으로 주요 정보)

## 🎯 특징
(성격, 태도, 특이사항)

## 💼 직업 정보
(직장, 직위, 전공, 경력)

## 📞 연락 정보
(연락처, SNS, 마지막 연락)

## 💡 협력 가능성
(분야, 강점, 주의사항, 추천 주기)

## 📝 회고 및 메모
(첫 만남, 인상 깊은 점, 협력 평가)

## 🔗 관련 정보
(링크)
```

---

### 📋 입력 항목별 가이드

#### 👤 기본 정보 테이블
| 항목 | 규칙 |
|------|------|
| 이름 | 정확한 이름 |
| 만난 날짜 | `YYYY.MM.DD` 형식 |
| 직장 | 회사명 (부서명) |
| 성격/태도 | 한두 줄 요약 |
| 지역/기타 | 거주지, 출신지 등 |

#### 🎯 특징
- 처음 인상
- 성격 특성
- 주목할 점
- 라이프스타일

#### 💼 직업 정보
- 회사명
- 직위/역할
- 전공/분야
- 경력 정보
- 전문성 평가

#### 💡 협력 가능성
| 항목 | 예시 |
|------|------|
| 협력 분야 | 특정 기술/프로젝트 |
| 강점 | 기술력, 인성 등 |
| 약점 | 제약사항, 우려점 |
| 추천 주기 | 월1회, 분기1회, 필요시 |

**협력도 평가 기준:**
- ⭐⭐⭐⭐⭐ (매우 높음) - 최우선 협력자
- ⭐⭐⭐⭐ (높음) - 적극 협력 권장
- ⭐⭐⭐ (중간) - 프로젝트 기반 협력
- ⭐⭐ (낮음) - 필요시만 연락

#### 📝 회고 및 메모
- 첫 만남의 상황/장소
- 가장 인상 깊은 점
- 우려사항 (있으면)
- 향후 협력 계획

#### 🔗 관련 정보
- 같은 직장 동료 링크
- 같은 분야 인물 링크
- 관련 프로젝트 링크

### ✅ 사람 추가 절차

#### Step 1: 새 파일 생성
```bash
# 새로운 사람을 만났을 때
# /archive/people/[이름].md 파일 생성
```

#### Step 2: 기본 템플릿 작성
```markdown
# [이름]

**만난 날짜**: [YYYY년 MM월 DD일]  
**현재 직장**: [직장명]

## 👤 기본 정보
...
```

#### Step 3: 각 섹션 작성
- 위 가이드라인 참조하여 작성
- 모르는 정보는 "(미기록)" 표시

#### Step 4: 목록.md 업데이트
1. [목록.md](목록.md) 파일 열기
2. 아래 위치에 링크 추가:
   - 직장/조직별 섹션에 추가
   - 협력도 랭킹에 추가 (필요시)

#### Step 5: Git 커밋
```bash
git add people/
git commit -m "Add [이름] profile"
git push
```

---

### 🔄 정보 업데이트 절차

#### 연락 후 정보 변경
1. 해당 사람 파일 열기
2. 변경 항목 업데이트:
   - 직장/직위 변경
   - 연락처 추가
   - 마지막 연락 날짜 갱신
   - 협력 가능성 재평가

#### 예시
```markdown
## 📞 연락 정보
| 항목 | 내용 |
|------|------|
| 마지막 연락 | 2025년 12월 27일 | ← 변경
| 상태 | 📞 연락 완료 | ← 업데이트
```

#### Git 커밋
```bash
git add people/[이름].md
git commit -m "Update [이름] profile: [변경 내용]"
git push
```

### 🎯 주기적 관리

#### 월별 검토
1. [목록.md](목록.md)에서 "정기 연락" 대상 확인
2. 월 1회 필요한 사람들에게 연락
3. 연락 후 정보 업데이트

#### 분기별 검토
1. 분기 연락 대상 확인
2. 협력도 재평가
3. 새로운 협력 기회 검토

#### 연 1회 전체 검토
1. 전체 네트워크 분석
2. 미연락 기간 확인
3. 네트워크 확대 계획

### 💡 팁과 주의사항

#### ✅ 권장 사항
- 📅 정기적으로 연락하기 (설정한 주기 준수)
- 💬 연락 후 정보 업데이트
- 🔗 관련 정보 링크 추가
- ⭐ 협력도 주기적 재평가

#### ⚠️ 주의사항
- **해산물 불가**: 김광호 - 외식 시 반드시 확인
- **반응 약함**: 유장준 - 연락 반응 기대 낮음
- **바쁨**: 부모님 동거자들은 시간 제약 있을 수 있음

#### 📌 특수 정보 기록
```markdown
## 🍽️ 식습관
| 항목 | 내용 |
|------|------|
| 불가능한 음식 | [음식] |
| 선호 음식 | [음식] |
```
